# 学序 StudyFlow 0.1.1-rc.53｜修复知到登录已成功但掌握度误报失效

## 修复内容
- 修复 Windows 安装版中，知到课程进度正常、扫码已成功，但「AI 掌握度」可能提示“登录态已失效”的问题。
- 根因是上游 ZHS 0.1.5 使用相对工作目录下的 `.zhs` 保存与读取凭证，而课程进度检测切换到用户主目录、Tauri Python Sidecar 可能继承安装目录。
- 统一独立 Sidecar 启动工作目录为当前 Windows 用户主目录，扫码登录、会话读取及掌握度模块访问同一份 `~/.zhs/cookies.json`。
- 只改变路径解析，不自动重登、不清空 Cookie、不改变课程进度与视频心跳，也不修改练习卷的保存或提交请求。
