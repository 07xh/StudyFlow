# 学序 StudyFlow 0.1.1-rc.27｜播放工作台与设置界面整理

## 本版改进

- **课程播放工作台**：移除重复的说明段落，优先展示课程名称、运行控制与真实进度信息；雨课堂仍明确提示“按已保存的课堂范围执行”，完整范围说明可展开查看。
- **知到 / 雨课堂章节页**：统一章节统计的文字格式，压缩占屏的核验摘要，保留服务器已核验、待核验、历史缓存、核验时间和单节复核入口等信息。
- **进度显示**：精简 ZHS 播放采样与雨课堂并发诊断中的重复说明。本地片段进度与平台核验的课程完成状态仍明确区分。
- **设置页**：知到参数分为“执行参数 / 执行范围”，雨课堂分为“播放参数 / 完成规则”；较长的技术说明可按需展开。
- **外观与维护**：非课程页面不再填充空进度，精简更新页文案，删除重复弹窗 CSS 与失效选择器。
- **质量保障**：新增 UI 结构回归测试，保留桌面与窄窗口布局、设置弹窗交互、服务器数据来源及既有功能检查。

## 保持不变

- **搜索**：课程搜索、章节放大镜、筛选、关键词匹配与清空操作没有修改。
- **平台功能**：没有更改知到、雨课堂、学习通的账号连接、原有执行器、心跳逻辑、课程读取、学习记录提交与进度核验。
- **更新方式**：仍由 GitHub Release 提供 Windows x64 安装包；更新包下载校验后需关闭学序手动安装。

## 发布验收

- 在独立 PR 中通过 Python 回归、React/Vite、浏览器布局、Windows NSIS 构建、安装/升级/启动/退出/卸载验证后合并。
- 主分支全部构建和安装检查通过后才正式发布候选版；课程完成状态始终以真实平台核验为准。
