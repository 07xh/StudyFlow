# 学序 StudyFlow 0.1.1-rc.39｜U校园图片/数字验证码登录体验修正

## 更新内容

- 明确 U校园账号登录中的人工验证为**图片或数字验证码**，不是手机短信验证码。二维码扫码属于另一种可选登录方式。
- U校园 AI 版“账号密码直接接口”若收到官方返回的 `UCAMPUS_LOGIN_VERIFICATION_REQUIRED`，学序自动打开专用的官方 WebView2 窗口，用户可在实际官方页面重新填写账号密码、查看验证码图片并手动输入。
- 更新 U校园登录页入口标题、说明文字、会话导入提示与桥接错误文案，避免误导用户输入短信验证码。
- 不读取或自动识别验证码图片，不伪造挑战值，不增加未知验证码接口。原本官方扫码、手动 Cookie 导入与 JWT 会话检查全部保留。

## 发布与实际验证边界

- 自动化检查仅覆盖代码、IPC、Windows 安装升级与 UI，不能证明官方账号可登录或验证码流程一定能完成。
- 需要使用本人账号，在真实 Windows EXE 中确认：官方页能看到图片验证码、能直接输入、提交后登录成功、会话导入后能读取课程列表。
- 如官方验证码由未列入窗口允许导航范围的其它域名跳转，需据实核对官方跳转网址后再做最小放行，不能臆测或扩大为任意域名。
- 不把输入验证码成功、Cookie 写入 Windows 凭据管理器或课程空列表当作成功接入证明。

版本：`0.1.1-rc.39`。
