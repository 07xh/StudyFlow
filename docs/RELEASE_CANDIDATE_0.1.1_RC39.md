# 学序 StudyFlow 0.1.1-rc.39｜LightC 风格启动动画

## 本次更新
- Windows 学序主窗口增加轻量品牌启动画面。HTML 首帧即显示学序标识与低饱和度双光晕，不再先显示空白 React 容器。
- 启动屏继承应用已保存的浅色、深色或跟随系统设置，优先展示主题正确的第一帧。
- 采用单 WebView 启动画面，没有第二个窗口、视频解码或额外的动画框架；支持系统减少动态效果设置。
- 启动画面最短约 650 毫秒，完成首次使用声明检查后约 240 毫秒淡出；后台连接状态检查和课程同步继续按原逻辑运行，不阻挡首页。
- 3.2 秒后出现“进入学序”按钮；12 秒后更新为慢启动提示。无伪造进度百分比。首次使用声明检查超过 8 秒显示原有可重试错误界面。
- 新增前端启动屏回归测试，检查静态首帧、主题匹配、幂等退出、慢启动跳过。
- PR 触发前端构建和回归检查；主分支发布策略保持不变。

## 继承功能
- 完整保留 rc.38 的 U校园官方登录窗口、有效期提示、会话清理及其他更新。
- 不改变知到、雨课堂、学习通、U校园的登录、课程读取、任务运行、进度证据与心跳业务代码。
- 保留用户已有数据和 Windows 凭据，不迁移数据库、不改登录态。

## 验收说明
- 只有 GitHub Actions 的正式 Windows 构建、安装升级检查及 GitHub Release 全部成功，才视为已发布。
- CI 的前端测试不等于已完成用户设备的视觉、性能与冷启动测试。仍需在 Windows 真机验证深浅色首帧、首次同意声明、异常重试和热启动。
- 启动画面只覆盖 WebView 开始渲染之后的加载时间，不能代替 Windows 原生进程初始化耗时分析。

版本：`0.1.1-rc.39`。
