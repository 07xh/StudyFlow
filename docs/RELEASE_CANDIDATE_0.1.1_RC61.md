# 学序 StudyFlow v0.1.1-rc.61｜共享题库 Token 管理升级

## 本次更新

- **多 Token 批量导入**：在同一题库配置区将多条 Token 按行粘贴，一次加密保存；自动去除空行、重复项，不覆盖原有凭据。单题库上限调整为 100 条。
- **每个题库独立使用策略**：固定默认 Token 或按查询次数依次选用已保存 Token；不会在限流、额度耗尽或网络失败时立即换号重复请求。
- **调用入口统一**：普通单题查题和知到掌握度默认继承题库 Token 策略，仍保留手动指定某一条的入口。
- **Token 状态检测**：在设置界面手动检查单条凭据，区分服务已识别、可能无效、无法确认和未检测；网络故障不会当作无效，更不会自动删除凭据。
- **剩余次数显示**：用户可主动查询题库返回的可用余量（这一操作可能消耗一次查询）；普通查题返回余量时也会更新最近记录和时间，缺少可信数值时显示未知。
- **本机安全**：Token 继续使用 Windows DPAPI 加密保存，不在设置或 IPC 返回中回显明文；保留旧版数据及旧 API 的兼容能力。

## 使用方法

打开 **设置 → 题库与搜题**，选择题库，将全部 Token 一行一条粘贴后点击「批量导入并加密保存」。
可选择自动轮流使用或固定使用。展开已保存 Token 列表后，按需点击「检测是否可用」或「读取余量（可能扣 1 次）」。

## 限制与说明

- 当前言溪题库的 Token 状态检测依赖接口返回信息，不是供应商承诺的稳定认证协议；实际是否扣费及真实 Token 状态仍需用户自行验收。
- 首次导入 Token 不会自动检测，打开界面也不会在后台轮询或消耗额度。
- 本次仅复用私人研究工具中与状态诊断有关的思路，没有引入自动注册、验证码处理、代理或多账号创建逻辑。
- 保留 rc.60 的知到掌握度章节范围选择、暂停流程与工作台界面。
- 发布工作流验证 Python、React、Windows NSIS 安装包构建及安装/卸载流程后才附上经验证安装包。
