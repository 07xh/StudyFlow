# 学序统一仪表盘与平台内登录重构

验收方向：用户提供的 LightC-UI 2.18.3 预览及后续明确的交互要求（2026-11-14）。

## 界面结构

- 使用石墨灰玻璃面板、绿色强调色、圆角侧栏与可折叠导航。
- 七个真实页面：首页、课程中心、学习任务、平台管理、学习记录、日志中心、设置。
- 首页展示知到与雨课堂平台卡片、真实课程统计和最近课程。
- 小窗口下导航收窄、平台卡片单列、登录表单单列、课程行换行。
- 深浅色主题、键盘焦点、禁用态和减少动态效果均保留。

## 平台登录归属

登录和授权入口必须位于对应平台卡片内部，不设置独立通用登录页面：

- 知到：卡片展开区包含学序内扫码与原版登录窗口入口。
- 雨课堂：卡片展开区包含 Session、CSRF、课堂 ID、学校 ID 与可选 Sign 配置。
- 登录展开状态按平台分别保存；登录按钮只操作所属平台。
- 雨课堂凭据继续写入 Windows 凭据管理器，不写入浏览器存储。
- “学习任务”页面独立管理知到和雨课堂原版任务进程，不与登录凭据配置混在一起。

## 数据真实性与旧功能保留

- 不写入设计稿中的示例课程、用户名或虚构进度。
- 课程来自真实平台读取结果；学习中、已完成和平均进度只统计具有 `server_verified` 与 `verified_at` 的课程。
- 本地原版任务进程的运行状态不等于平台已确认学习进度。
- 保留原知到 ZHS 0.1.5 与雨课堂原版心跳代码；UI 仅调用既有进程控制接口，不重写心跳生成、发送或进度算法。
- 保留原二维码登录、课程同步、雨课堂会话管理、视频元数据读取、主题与本机偏好。

## 窗口适配

Windows 默认窗口 1150×780，最小窗口 720×560；布局使用弹性网格和断点规则。高 DPI 的最终观感仍需在 Windows 真机及不同缩放比例下验收。

## 源码与视觉实现边界

本轮按用户提供的预览和交互目标，使用 StudyFlow 自有 React/TypeScript 组件与 CSS 实现；没有把 LightC 的受限源码、组件或资源复制进公开仓库。

## 代码入口

- `frontend/src/ui/AppShell.tsx`：七项导航、主题、刷新和可折叠侧栏
- `frontend/src/ui/PlatformCard.tsx`：平台卡片与所属登录展开区
- `frontend/src/components/ZhidaoMigration.tsx`：知到登录面板
- `frontend/src/components/YuketangLoginPanel.tsx`：雨课堂会话配置
- `frontend/src/components/LegacyPlaybackPanel.tsx`：原版任务进程控制
- `frontend/src/App.tsx`：真实数据、统计、任务、记录和本机操作日志
- `frontend/src/ui/foundation.css`：石墨玻璃主题与响应式样式
- `frontend/tests/`：平台登录归属、真实数据和旧功能接线回归

通过 CI 不代表已完成 Windows 真机登录与 UI 截图验收。
