# 学序 StudyFlow 0.1.1-rc.26｜章节交接进度显示修复

## 本版更新

- 继承 rc.25 的章节运行路：不同章节独立调度，同一章节按真实资源顺序依次处理；原有并发数、停止控制和本机参数不变。
- 修复从一个章节交接到下一章节时“仍显示运行，但进度条突然消失”的显示问题：新资源已运行、但尚未提供有效本地百分比时，保留动态等待态进度条。
- 在章节交接、暂时没有运行中资源的短窗口，显示下一章节名称与资源分配状态，不再只有空白区域。
- 若进度采样过期，百分比仍保持未知，不继承上一视频百分比；只有收到当前资源的新样本才显示确定进度。任务退出后仍需平台服务器核验。
- 新增跨章节交接、采样缺失、恢复采样、轮询过期的 React 组件测试，并保留历史回归验证。

## GitHub 最新版本入口修复

- 修复 EXE 内“GitHub 最新版”实际只打开全部 Releases 列表、无法定位 rc.25 等新版本的问题。改为按已发布语义版本号寻找最新且包含可校验 Windows x64 安装包的版本，直达该版本页面。
- “全部历史版本”保持单独入口；同时覆盖版本设置和更新日志弹窗。
- GitHub 返回顺序异常、正式版 Latest 不包含 RC、网络故障或无可校验安装包时不再误导用户，原生浏览器跳转严格限制到本仓库版本标签。

## 注意与验证

- 仅更新学序本地展示，不修改 ZHS 原版播放、上报或心跳实现；若真实资源进程卡住不退出，本版不会绕过平台要求或虚报完成。
- CI 需通过 Python、React、Windows NSIS 构建、安装/升级/启动/卸载验证后发布。实际学习平台的学习完成状态以服务端读取为准。
- 升级后原有正在运行的任务需要停止再启动，才会采用新的版本逻辑。
