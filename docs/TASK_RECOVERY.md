# 学序任务断点恢复契约

该功能只恢复 **用户确认过的任务**，复用知到 ZHS 与雨课堂原有的播放进度读取逻辑，不修改两者心跳算法。

- 任务快照只包含原始任务配置、非敏感课程标识、任务运行标识和 30 天有效期，不包含 Cookie、CSRF、Sign 或平台返回内容。
- 雨课堂使用本机随机盐 HMAC 绑定当前会话、Sign 与课堂范围。密钥只存 Windows 本机 LOCALAPPDATA；标识不具备登录能力。
- 恢复前检查当前原版进程状态和平台会话。知到必须通过只读服务器课程进度核验；雨课堂需要会话标识相同、已授权课堂相同及至少一条可核验的真实视频进度记录。
- 原版执行器的 OS 文件互斥锁只允许每个平台同时存在一个 StudyFlow 子进程；即使主窗口崩溃、旧子进程残留，新子进程也不执行。错误码 10 为已占用；11 为锁不可用。
- 正常完成的进程退出码 0 清理本次恢复提示，但不等于服务器确认学习完成；异常退出保留本机恢复提示。主动停止清除记录。
- Windows 真机验收仍需覆盖：异常主程序退出、旧进程残留、手动停止、网络错误、跨账号或跨课堂变化、保存配置/首次安装、安装卸载及服务器数据读取。
