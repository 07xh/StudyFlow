# StudyFlow v0.1.1-rc.65｜关于与开源：长文档查找及无障碍交互

## 本次优化
- **离线文档搜索**：「关于与开源 → 开源与许可」阅读 GPL、来源登记、条款或隐私说明时，可按中文、英文或包含特殊标点的字面关键词查找、看到匹配总数，并通过上一处/下一处定位。
- **长文本性能**：完整保留并展示原始许可证内容；为避免极短关键词生成大量前端节点，最多高亮和导航前 250 处命中，仍显示精确总命中数；不修改原法律文档内容。
- **键盘与可访问性**：「产品概览 / 开源与许可」增加左右方向键与 Home/End 切换、当前页与关联内容标识；文档阅读仍支持 Esc 返回列表及返回后恢复焦点。
- **版本状态修正**：Windows 程序版本读取异常时展示「版本暂不可用」，不再无限显示读取中。
- **文案准确性**：源码与来源入口明确包括知到、雨课堂、学习通及第三方许可证登记。
- **测试**：新增中文、英文、正则特殊符号的字面查找测试，大量匹配数上限测试，文档查找导航和无障碍交互回归。
