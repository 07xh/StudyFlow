# StudyFlow 学序 0.1.1-rc.11｜雨课堂逐节视频进度

## 新功能
- 课程工作区的「章节与学习进度」按章显示每节真实视频的服务器进度条、已核验百分比、最后播放位置及已完成状态。
- 复用原版雨课堂只读 `/video-log/get_video_watch_progress/` 查询，数据取自当前会话的真实课堂和视频 leaf ID。
- 首次读取 8 节，提供「继续核验」按页查询；每批最多 3 个独立 Session 并发，不创建新心跳、不修改原版播放器。
- 服务器无记录或认证失败时标注「未核验」，不制造 0% 或已完成；严格防止 99.999% 被显示成已完成 100%。
- 切换课堂、失去连接、范围未保存或刷新失败，清理对应旧进度；不可把日志模拟进度视为服务器进度。
- 保留当前 rc.10 的版本更新诊断、LightC 弹窗与知到功能。

## 验收
- Python、React、Windows Rust + NSIS 完整 CI 和安装/升级/卸载测试通过后才正式 Release。
- 真正的雨课堂账号与服务器单视频进度必须在用户 Windows 设备验收；离线 CI 不代表平台已核实。
- 当前范围仅为已明确识别的 `leaf_type=0` 视频。PPT、图文类并不提供同样的视频百分比，本次不虚构。
