# 学序 StudyFlow 0.1.1-rc.7 · 心跳任务运行状态与 Windows 停止可靠性

## 主要修复

- 基于 rc.6 的课程中心、LightC 界面、ZHS 单次任务隐私安全诊断和平台接入，不回退原有功能。
- 知到原版 ZHS 及雨课堂任务：`legacy_start`、`legacy_status`、`legacy_stop` 转入 Tauri 阻塞线程池，避免 Windows 进程操作占用 IPC/UI 调度线程。
- 状态轮询短暂失败时保留上一次由学序托管的运行标识，以便重新查询并核对后停止；隐藏失效的本地进度和旧退出诊断，阻止未知状态下重复启动。
- 保留运行 ID 验证、进程树清理、限时停止和服务端只读进度核验。
- 离线 ZIP 仍按 Git blob 哈希验证 47 项以上原始源码文件，不依赖压缩包自带 Git 历史；有 Git 历史时保留工作区差异检查。

## 保持不变

不新增心跳执行器，不修改原版 ZHS 0.1.5、雨课堂 `main.py` 或心跳发送算法；本地采样和退出码不等于服务器确认完成。

## 发布门禁

只有 Python、React 构建与测试、Windows Rust/Tauri/NSIS 构建和安装/卸载检查全部通过，才由主分支发布工作流自动创建 `v0.1.1-rc.7` 预发布。不得覆盖之前的 rc.6。

真实 Windows 账号上的扫码登录、课程读取、开始/停止、恢复与实际服务器进度核验仍须按实机验收记录单独确认，不因 CI 通过而宣称已验收。
