# 学序 StudyFlow 0.1.1-rc.32｜知到章节进度采样状态修复

## 本版更新

- **知到章节队列采样提示修复（PR #159）**：文章、PPT 等非视频资源不再因没有视频播放百分比而被误报为“进度采样暂不可用”。
- **视频初始采样与过期区分**：视频启动后先显示等待真实采样；长时间无有效数字或已有数值过期时才显示采样不可用，旧数值不会沿用到下一视频。
- **任务状态与进度含义更明确**：区分队列读取异常、视频采样缺失和阅读类资源执行状态；本地采样不代表知到服务器确认完成。
- **补充 Python 和 React 回归测试**：覆盖视频未采样等待、数值过期、非视频资源状态和界面文案，避免相同误判再次出现。

## 保留与限制

- 继续沿用已集成的 ZHS 0.1.5 原版运行器；不修改网络发送逻辑与心跳生成方式。
- 本版本不声称解决所有真实视频采样失败。如果运行中的视频始终无百分比，需要使用本人 Windows 环境进一步核对原版输出、临时快照生成及进度读取。
- 课程总进度与真实完成状态仍需知到服务器只读核验，不从本地视频百分比推断。
- 本候选版基于 rc.31 及主分支已合并的 PR #159；不包含仍处于独立开发分支的其他平台新功能。

## 验收与安装

版本：`0.1.1-rc.32`。新的 Windows x64 NSIS 安装包独立发布，不覆盖 `rc.31`。自动化测试、构建、升级与卸载检查通过后才会生成 GitHub Release；Windows 本机真实课程采样仍需单独验收。

在学序「设置 → 版本与更新」选择 Beta 通道，检查更新并查看本版更新说明；安装前先结束正在运行的学序任务。
