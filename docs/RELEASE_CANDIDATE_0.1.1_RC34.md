# 学序 StudyFlow 0.1.1-rc.34｜四平台兼容与 U校园接入

## 本版更新

- 保留 **rc.31–rc.33** 的知到并发采样、学习通任务进度、队列和界面修复，不重置已完成的主分支开发。
- 增加 U校园AI 独立平台入口、SSO 账号登录、系统凭据存储、真实课程及单元/任务读取。
- 增加服务器进度只读核验，并支持用户自愿启用的重启后恢复核验：保存单元 ID 和匿名会话指纹，有限频与跨账号隔离机制，不保存密码和 Cookie。
- 修复课程 ID 中加号和短横线的只读请求兼容、会话错误提示、窄窗口操作区布局、旧进度误显示等问题。

- **知到停止→重启修复（PR #164）**：调整停止后的进程锁交接和等待机制，避免旧运行器尚未释放互斥锁时重新启动；保留清晰错误提示。
- **Windows 子进程树回收（PR #165）**：为学序管理的 ZHS 子进程使用 Windows Job Object，确认进程清理后再报告“已停止”；应用退出时保留受控的兜底清理，仅针对学序启动的子进程，不影响其他 ZHS 实例。
- **兼容升级**：合并最新主分支功能，既有知到、学习通、雨课堂及 U校园模块均不因进程管理修改而回退。

## 验收边界

- 不将本地模拟时长当作完成记录；只读断点恢复不会补发虚构观看心跳，亦非 Windows 开机自启动。
- U校园学习事件的实验性模块不等于生产环境验收，本版不承诺其被当前 U校园服务器接受。
- 自动化 Python/React/Windows 测试并不代替用户本人账号的真实课程读取与服务器状态回读检查。
- 如遇验证码、限流或接口变更，应按平台官方验证流程处理。

## 安装与升级

版本：`0.1.1-rc.34`。此版本仅在主分支合并且 Windows NSIS 构建、安装/升级/卸载验证通过后由发布工作流生成；升级前请先停止运行任务。
