# 学序 StudyFlow 0.1.1-rc.51｜知到全课程 AI 掌握度自动练习

## 全课程掌握度
- 在知到 AI 课程工作台「AI 掌握度」新增后台自动任务：一次扫描该课程全部章节及知识点，按设置的目标分数逐项处理；已达标知识点不重复练习。
- 自动新建知识点练习、逐题保存、回读服务器答题卡确认全部保存，提交本轮后读取官方判分和掌握度；只有服务器确认达到目标，才标记为达标并进入下一知识点。
- 不再需要手动点「再练一轮」。支持暂停、继续、停止，显示知识点任务列表、已达标数、需处理数、重练次数、题库命中与 AI 调用次数。
- 可设置目标分数（最高 100）、单点最多轮数、连续不涨分停止条件、最长执行时间；遇到无法确认的提交不重新发送同一张卷，并记录状态供处理。

## 首轮四种作答模式
1. **题库与本地有限试答**：不调用 AI，先用已经验证的题库，未知选择题尝试未试过的有限组合。
2. **题库优先 + AI**：已验证题库直接用，未命中时可向 DeepSeek 请求建议答案；结果以官方判分为准。
3. **首轮 AI 优先**：第一轮优先使用 AI 建议；**第二轮起使用已验证题库或有限试答**，不再对新题自动调用 AI。
4. **首轮随意作答并提交**：第一轮不查题库、不用 AI，单选/判断取一个实际选项，多选取一个实际选项，未知填空用占位文本；不是空白卷。提交后读取官方反馈，第二轮优先复用已验证答案。

只有用户主动选择启用 AI 才会发送题干和选项给 DeepSeek；API Key 仅供本次任务使用，不写入本地任务或题库。可设 AI 请求次数上限。

## 保留与兼容
- 复用 rc.50 的知到纯 HTTP 协议、授权会话、掌握度回读和手动练习界面；不打开独立浏览器或答题窗口，不改 ZHS 视频心跳。
- 本地 SQLite 题库只把官方判对或明确公布的答案视为已验证答案，AI 建议及首轮随意作答不直接登记为正确。
- 自动执行期间禁止手动对同一课程同时开卷/答题/交卷，以免状态冲突。
- 原有 rc.50 及此前的登录、视频播放、学习记录和课程功能继续保留。

## 验证与已知限制
- Python、React UI/IPC、Windows NSIS 安装包与运行时测试通过后才正式发布此 RC。
- **仍需真实账号试验**：平台是否允许反复重练、未知填空是否公布标准答案，以及官方掌握度是否能够到达 100。以上均由平台决定。
- 未公布答案的填空题只占位尝试一次，无法确认结果或达到轮数限制的知识点标记为需处理，不宣称已达标。
- 本版本仅用于知识点练习；不表示正式考试支持自动作答。
