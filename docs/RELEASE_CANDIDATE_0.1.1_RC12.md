# 学序 StudyFlow 0.1.1-rc.12｜雨课堂界面与知到统一

## 此版本更新
- 雨课堂课程详情与知到「章节进度」使用统一卡片样式、三列进度摘要和绿色服务器进度条。
- 新增「全部 / 待完成 / 已完成 / 未核验」筛选，仅统计当前已读取的视频；“未核验”不等于 0% 或待完成。
- 章节支持逐个展开/收起，也支持全部展开/收起；默认只展开首个符合筛选条件的章节，减少长列表占屏。
- 保留 0.1.1-rc.11 的逐视频服务端只读进度、进度时间和后续分页核验接口。未改动雨课堂/知到运行器、登录或播放器。
- 统一明暗主题、窄屏布局和进度口径说明。

## 构建与验收
- Release 发布受前端生产构建、UI 回归测试、Windows NSIS 构建和安装/升级/启动/卸载验证共同门禁。
- CI 以模拟响应核对 UI/数据契约，无法代替 Windows 实际雨课堂账号与服务器数据验收；不要把未核验内容当成完成进度。
- 安装包保留用户现有本地数据；使用前请备份重要配置。
