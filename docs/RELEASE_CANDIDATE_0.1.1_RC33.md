# 学序 StudyFlow 0.1.1-rc.33｜知到多路视频进度采样兼容修复

## 本版更新

- **知到多路进度采样兼容（PR #161）**：补齐 ZHS 0.1.5 共享课程输出的 `playing 视频ID [进度条] 百分比` 格式识别。此前只识别智慧课程的 `playing [进度条] 百分比`，会漏掉部分真实控制台进度行。
- **每个视频独立采样**：继续通过每个子进程的唯一临时标识保存、读取百分比，不将一条视频的采样复制到另一条。
- **保留原版代码**：ZHS 0.1.5 原始控制台观察器与课程执行器不修改；仅改学序的本地只读解析适配器。
- **回归测试**：增加两路 AI/共享课不同格式输出、分段写入、数值越界、资源切换清空旧位置等测试。

## 验收边界

- 本地百分比只来自有效、及时的控制台数字；任务进程“运行中”不保证该视频已经产生有效采样。
- 本轮解决已确认的输出格式漏识别。截图中第二条视频若实际没有输出有效数字，仍会显示等待采样，不能用计时器推测百分比。
- 本地播放位置不是服务器确认的课程完成进度。原版心跳、请求发送和服务器学习记录逻辑不因本次 UI 采样兼容修复而改变。
- 自动化构建与 Windows 安装测试不等同于真实账户现场验收。要验证全部并发路数，请在本人 Windows 环境运行并检查每一条进度。

## 安装

版本：`0.1.1-rc.33`。Windows x64 NSIS 安装包通过主分支发布工作流独立生成，不覆盖 `rc.32`。在学序「设置 → 版本与更新」选择 Beta 通道检查更新，关闭当前运行任务后升级。
