# 学序 StudyFlow 0.1.1-rc.16｜更新后首次启动弹窗与雨课堂定向进度更新

## 更新体验
- **新版本首次启动更新说明**：安装新版后第一次进入学序，自动显示对应 GitHub Release 的真实更新内容。关闭后同版本不再反复显示。
- 全新安装不会触发升级提示；已有旧版本本地状态的用户首次进入可显示一次更新说明。
- 支持从多个旧版跳到新版本时合并展示已发布版本的更新记录，避免遗漏改动。
- 「设置 → 版本与更新 → 历史更新日志」提供手动查看入口。
- 更新说明通过只读、校验参数的 IPC 获取，直接按文本呈现，不执行网页脚本；无法联网时提供官方发布页入口，仍可正常使用学序。

## 雨课堂
- 保留 #99 已合并的首次进入全课只读核验、后续手动刷新、播放视频时仅对匹配视频的进度进行定向只读复核。
- 保留先前的知到、雨课堂章节筛选、搜索、课程详情 UI 与本地进度证据表达，未改动原有播放器/平台上报流程。

## 构建与验证
- 从 `main` 合并最新变更，保留雨课堂的本机缓存、核验与播放观察优化。
- Python / React / Windows NSIS 的自动化 CI 以及全新安装、重复安装/升级、启动、卸载的离线烟测作为正式候选版的门禁。
- 离线 CI 不能替代用户真实 Windows 环境中知到、雨课堂账号登录、课程读取和服务端进度的实际验收。
