# 学序 StudyFlow 0.1.1-rc.16｜雨课堂首次全量核验与播放增量进度

## 雨课堂课程进度核验策略

- **首次进入课堂：** 只读分页核验所有可识别视频一次，显示确实来自平台服务器的进度、完成状态与核验时间。
- **再次打开课堂：** 在学序本次运行期直接显示已核验缓存，不重新发起全课扫描。重启应用或更换账号/课堂范围后，首次进入仍会重新验证。
- **手动全课刷新：** 点击「重新核验全课」才重新逐批读取；部分网络错误时保留已有真实服务器记录，并可继续未完成批次。
- **播放期间增量核验：** 学序观察本地雨课堂任务正在观看/刚处理完的视频，只有视频名称在当前课堂中**唯一匹配**，才使用已有的只读平台接口单视频复核，不因播放中每次进入章节界面而扫描全课。
- **不重复核验已完成记录：** 已由服务器确认完成（100%）的视频不再因为播放日志触发单视频复核；手动全课刷新仍可复查。
- **正确性与隐私：** 不将本地播放百分比、任务日志或未知状态写成服务器已确认完成；无法唯一匹配的视频和服务器未返回可信结果时保留原已确认记录。退出登录、修改课堂范围后令旧结果与旧请求无效。

## 继承的现有功能

- 延续 rc.15 的知到/雨课堂统一课程章节、搜索、状态筛选和响应式视觉布局。
- 保留已有课程读取、登录、播放器与任务执行能力；此次只改变雨课堂**读取和显示服务器核验结果**的时机，不改动平台的学习进度上报逻辑。
