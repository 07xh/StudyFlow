# 学序 StudyFlow 0.1.1-rc.16｜知到 ZHS 正在处理的资源可见性

## 本次修复
- 修复知到原版任务运行面板只有「当前知识点资源 4/4」，却无法判断正在处理视频、PPT 还是文章的问题。
- 从已有的上游资源模型中只读观察真实资源类型、短名称，使用本地任务快照经 Tauri/Rust 安全校验后展示在课程工作台。
- UI 增加「正在处理 · 视频/PPT/文章」及资源名称；资源变化时重置单段视频位置，不把本地片段百分比误称为官方课程进度。
- 为 AI 课程保留按课程选择全部、视频、文章/PPT 的选项，未选择时沿用原有执行范围；保留共享课原有处理路径。
- 保留 rc.15 已发布的知到/雨课堂统一章节筛选、课程记录、状态分类和旧版更新检查修复。

## 雨课堂：首次全课核验，播放期间按视频更新
- 首次进入雨课堂课程后逐批核验真实服务器记录一次；返回列表再次进入时复用本次应用运行期的缓存，不重复全课扫描。
- 需要复查时手动点击「重新核验全课」；网络错误不把旧服务器进度清空，部分成功可以继续未完成批次。
- 课程播放任务运行时观察当前视频：仅当其名称在当前课程视频列表中唯一匹配，才通过只读服务器接口核验该视频，不以本地播放百分比冒充官方进度。
- 已由服务器确认完成的视频不再因为播放日志重复读取；无法匹配、缺少服务器证据时不猜测完成状态。
- 更换登录账号、课堂范围或退出平台会使旧进度缓存失效；应用重启后首次进入仍需重新核验。

## 不变的部分
- 不修改原版 ZHS 心跳报文、发送算法或校方进度记录。
- 不将本地模拟片段位置当成服务端真实学习进度，也不宣称已完成课程。
- 资源名来自已有上游读取；当缺失或不可信时界面明确显示未提供，不编造标题。

## 发布与验收
- 必须完成 Python 回归、React/TS/UI/IPC、Windows NSIS 构建与安装/升级/启动/卸载门禁后，才能由 main 发布一次性 rc.16 候选包。
- 仍需在用户 Windows 真机上以真实课程验证视频、PPT、文章切换、名称一致性、停止/重新启动及服务端只读进度；CI 不等于真实账号验收。
