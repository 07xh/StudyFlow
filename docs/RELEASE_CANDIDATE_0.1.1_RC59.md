# StudyFlow 0.1.1-rc.59｜知到自动掌握度接入共享题库

## 新增

- **共享题库可用于知到全课程自动掌握度**：沿用原有的 `zhidao.mastery.auto` 后台调度器，不另起独立窗口或第二套 HTTP 提交机制。
- 在「全自动掌握度」弹窗新增「使用共享题库自动查询未命中题目」可选开关。开启后可选题库来源（当前言溪）与已保存的 Token。
- 支持「本次最多外部题库请求」限制（1–200，默认 40），展示外部查询数、解析命中数和失败数；同一知识点的相同题目不反复请求第三方。
- 标准化题目数据后调用 rc.58 的 `questionbank.query` 核心服务；题库返回的字母选项或明确的选项文本转换为知到所需的真实选项 ID，填空文本保持原样。
- 支持原来的四种答题策略：
  - **本地题库优先**：本地已验证答案 → 外部题库 → 原有有界试答。
  - **本地题库 + AI**：本地已验证答案 → 外部题库 → AI → 原有有界试答。
  - **首轮 AI 优先**：首轮 AI 优先；之后已验证本地题库优先，可查询外部题库。
  - **首轮随意作答**：首轮保持原行为；后续可使用官方判分回读与外部题库。

## 重要行为与限制

- 这是对现有知到**练习题**功能的可选增强，**关闭外部题库开关时行为保持 rc.58 不变**。
- 远程答案始终标记为**未经官方核验的参考建议**。只有真实官方判分结果明确确认后，才会写入本地已验证 SQLite 答案库。
- 所有本地配置仅持有提供方 ID 和 Token ID；完整 Token 继续由 Windows DPAPI 保护，运行状态文件不保存 Token 明文。
- 未命中、答案不符合题型、网络错误或额度限制时，返回原有答题策略；不会自动轮换 Token、重复查询同一道题或重发不明确的交卷 POST。
- 如果未保存或未选择有效的外部题库 Token，外部查询开关开启时禁止启动。
- `ai_first` 的首轮 AI 优先、`arbitrary_first` 首轮随意作答逻辑不受此功能覆盖。
- 查询可能消耗第三方题库额度。没有使用真实用户 Token 验证上游答案质量、额度和计费。
- 实际掌握度以知到服务器判分和回读为准，**不保证自动达到满分**。
- 当前改动仅在知到 AI 掌握度中接通自动共享题库；普通作业等其他栏目仍需接入真实题目读取数据。

## 使用

1. 「设置 → 题库与搜题」配置好言溪 Token（允许多条）。
2. 知到 AI 课程 → 「全自动掌握度」→ 勾选「使用共享题库自动查询未命中题目」。
3. 选择对应题库和 Token、设置外部查询次数上限，再选择已有首轮策略。
4. 点击「开始全部章节」，使用原有暂停/继续/停止、日志和进度查看。
