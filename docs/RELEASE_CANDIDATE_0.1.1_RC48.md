# 学序 StudyFlow 0.1.1-rc.48｜独立开发者网站介绍页面

## 设置界面
- 全局设置侧栏新增独立的「开发者网站」栏目，不再与「关于与开源」文档入口混排。
- 进入栏目后，先展示应用内的开发者网站简介，再提供单独的「访问开发者网站」入口。
- 网站使用现有系统默认浏览器打开命令，网页不嵌入 StudyFlow；保留网页版 HTTPS 链接和新窗口安全属性。
- 「关于与开源」只保留使用条款、隐私说明、GPL 开源许可与原版源码说明，不重复展示开发者网站链接。
- 设置弹窗、键盘操作、主题和原有页面结构保持一致；入口仅显示「开发者网站」，不在名称后附加域名。

## 沿用 rc.47
- 保留 ZHS 无资源知识点识别、在既有章节队列中执行一次官方页面进入记录并回读学习进度的实验性逻辑；移动端 studyProgress 优先于过时的 ZHS 目录进度。
