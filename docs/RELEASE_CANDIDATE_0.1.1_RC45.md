# 学序 StudyFlow 0.1.1-rc.45｜ZHS 必学/选学识别与服务器记账核验

## 本版修复
- **必学和选学分类**：保留 ZHS 返回的 `resourcesSyncType`；1 为必学，其余已知值为选学，原始字段缺失时标记“分类待核验”，不冒充已确认的必学。默认不开启选学处理；只有用户在 ZHS 设置中开启后才纳入执行队列。
- **逐项服务器回读**：单路与多路 ZHS 原版资源队列（包括 AI 的阅读/PPT）均在每个资源的原版处理结束后执行一次独立只读检查。共享课核对服务端 `studyTotalTime` 和 `watchState`，AI 课程核对 `schedule` 和 `studyStatus`。有增量或者服务器已标记完成才视为已确认有记录；只读回读不修改进度。
- **正确展示未确认状态**：原版播放器退出但服务器记录没有变化时返回专用状态 16；当前无法获取服务器状态时返回状态 17；两者在队列中均显示“服务器未确认”，不再将本地成功退出冒充服务器已增加进度。
- **本地阈值与未完成状态冲突**：AI 视频服务器仍标记未完成、但播放器因本地阈值已到而不会发出任何新增进度时，明确标记未确认，避免空跑后显示完成。
- **失败状态传递**：ZHS 0.1.5 的隔离可靠性补丁中，AI 资源提交失败累积后抛出异常而不是正常返回，使 StudyFlow 能得到真实非零退出码；不改网络协议和上报字段。
- **队列显示与类型约束**：Rust 安全解析器、React 队列类型及界面同步支持“必学 / 选学 / 分类待核验”“服务器未确认”，并严格校验只允许受控状态。
- 新增离线必学/选学分类、单资源服务器回读、阈值冲突及失败退出路径的回归测试。

## 验收边界
- 服务器“观看时长增长”和“整个视频/知识点完成”属于不同证据；读到增量只证明对应服务器字段改变，不代表课程最终完成。
- 本版不更改原版 ZHS 0.1.5 心跳请求、发送参数、发送频率及观看执行算法，不作重放或者补造进度；只添加只读回读与错误判定。
- 网络请求被接受但平台延迟记账时，单次即时核验可能显示“未确认”，用户可稍后在课程详情重新执行官方只读核验；状态不是认定作弊或平台拒绝。
- Windows NSIS 构建、自动测试与真实知到账号的服务器写入验收必须分别确认；CI 成功不等于线上已确认。
- AI 必学/选学归类适用于 ZHS 智慧课程资源；普通共享课视频标注“共享课”，不伪造选学属性。

版本：`0.1.1-rc.45`。
