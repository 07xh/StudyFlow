# 学序 ZHS 0.1.5 原版观看参数

对照原版 `pjm314159/zhs@v0.1.5` 的 `zhs play` 命令，学习雨课堂的独立设置、校验与启动透传方式，但不复制雨课堂心跳字段。

| 学序选项 | 上游 CLI | 适用范围 |
| --- | --- | --- |
| 倍速（1–2×） | `--speed` | 知到共享课及 AI 课程 |
| 单次时间限制（0–1440 分钟） | `--limit` | 0 使用上游默认 |
| 学习选学资源 | `--learn-optional` | AI 课程 |

配置保存在 `%LOCALAPPDATA%/StudyFlow/zhidao/zhs-task-settings.json`，不改动原始 `~/.zhs/config.toml`。
校验由 React、Rust、Python 三端执行。无新版参数时保留原旧入口。
原 ZHS 0.1.5 没有公开的心跳间隔或并发数量设置，因此本次不添加无效开关，也不改原版心跳生成和发送代码。

原版视频完成阈值不属于当前 `play` CLI 参数，暂不提供可调 UI。
已使用上游原版 CLI 执行；AI `.cmd` 回退若无法应用非默认自定义选项会明确返回运行时不可用，不会伪称设置已生效。

CI 只能验证参数持久化、启动链路与原版源码未变。Windows 真机登录、任务执行、服务端进度仍需实际核验。
