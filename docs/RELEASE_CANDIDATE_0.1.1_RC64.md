# StudyFlow v0.1.1-rc.64｜关于与开源界面重构

## 本次更新

- **关于与开源独立页面**：不再借用知到账号/数据管理组件；产品概览与开源/许可分为清晰的二级内容，布局紧凑、支持小窗口与键盘操作。
- **产品信息**：从桌面程序读取当前版本，集中展示项目定位、技术组成、源码主仓库、GitHub Releases 和独立开发者网站入口。
- **开源与上游**：提供 StudyFlow、ZHS 与学习通 GPL 上游参考仓库的明确链接，区分软件开源来源和第三方教学平台官方身份。
- **文档阅读重构**：使用原有的 `studyflow_read_document` 原生读取服务，直接在设置浮窗内阅读 GPL v3、源码来源、使用条款及隐私说明；移除原先叠加的第二个法律文档对话框，不依赖知到 Python sidecar。
- **外部网站边界**：Rust 新增固定白名单的开源仓库外部打开命令，使用系统默认浏览器，不接受前端传入任意 URL。
- **清理与验证**：移除旧知到关于弹窗状态、遗留 CSS，更新路由契约并新增版本读取、文档切换、链接打开、错误和 Web 预览回归测试。
- **共享题库兼容**：包含上一轮 PR #216 对第三方题库结果的规范化处理，阻止意外透传上游原始调试字段。

## 不受影响

知到连接诊断、退出登录、课程缓存管理、原版播放器和心跳执行；雨课堂、学习通及 U校园现行适配器；旧 Token 加密保险库和迁移机制均保持原样。

## 验证

需要 Python、React/UI/IPC 与 Windows NSIS 完整构建/安装升级卸载检查。CI 通过不等于真实平台账号完成在线验收。
