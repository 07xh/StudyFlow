# 学序 StudyFlow 0.1.1-rc.24｜知到按章节并行修复

## 修复双路仅运行一项

- 旧 rc.23 会被同一章节的视频后续文章/PPT 全局独占屏障卡住，即使设置双路也只有一项运行。
- 现在按实时服务器课程目录建立 **章节运行路**：不同章节可以同时执行；同一章节的所有视频、文章、PPT 保持原本顺序。
- AI 课程按服务器返回的 theme 分章、知识点+资源 UID 精确锁定；共享课使用服务器章节的 videoId 映射，不从视频标题中的 1.8、1.9 等编号推断。
- 单章没有第二路可执行时，界面如实显示只有一项运行，不强行凑满设置数。
- 继续支持 1–3 路设置、单项停止、自动补位、总停止、执行目标阈值、跳过已完成及单资源进度。进度面板改成章节分组。
- 兼容旧版任务的无章节遥测数据，新增 Python 子进程调度/目录模拟、Rust 解析、React 组件回归检查。

## 注意

本地片段位置、子进程正常结束不代表平台服务端已确认完成，界面仍以真实服务器进度核验为准。跨章节同时执行的真实账号兼容性还需在 Windows 上单独验收。对已在运行的 rc.23 原进程，升级后需停止原任务并重新启动才能采用新的章节调度规则。

## 自动化验证

合并前需通过 Python、React、Windows NSIS、安装升级/启动/卸载测试。合并到主分支后由对应 Windows CI 对准确的主分支提交一次性发布本候选版。
