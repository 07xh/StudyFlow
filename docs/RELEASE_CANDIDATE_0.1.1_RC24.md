# 学序 StudyFlow 0.1.1-rc.24｜知到 ZHS 启动可靠性修复

## 修复内容

- 知到共享课程入口使用 ZHS 0.1.5 能完整解析的标识。对于含特殊字符的课程路由，不再传递会被原版 URL 解析截断的字符串；存在可信数字课程 ID 时使用原版课程列表解析，否则明确拒绝错误路由。
- ZHS 本机参数读取失败时明确提示，可重试读取，或由用户明确确认后只覆盖当前课程的本机参数为默认值；不删除账号、Cookie、课程缓存或已核验进度。
- 切换课程、重新加载参数时清除上一课程的本地暂存状态，防止误用。
- 已保存的章节/资源范围无法在当前目录核验时显示说明，并提供用户主动选择整门课程的入口；不会自动扩大任务范围。
- 保留 rc.23 的同一课程视频队列与各课程独立执行阈值；不改动原版心跳协议或把本地任务进度当作平台完成状态。

## 验证与限制

- 针对修复代码：300 项 Python 回归测试和 170 项前端测试通过；TypeScript/Vite 生产构建及浏览器布局检查通过。另由 Windows GitHub Actions 验证 NSIS 构建和安装升级。
- GitHub Actions 绿灯只能证明构建和离线回归；知到真实账号的课程访问、平台记账、并发兼容性及具体退出码原因，仍须在 Windows 真机核对。
- rc.23 是上一版，rc.24 是单独补丁；升级后可在学序内查看此更新说明。
