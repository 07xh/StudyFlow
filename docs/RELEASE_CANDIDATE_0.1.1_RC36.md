# 学序 StudyFlow 0.1.1-rc.36｜公开 GitHub 代理与可信断点续传

## 本版更新
- 默认使用 GitHub Releases 官方 API 获取版本、日志及 SHA-256，**仅代理公开安装包文件下载**，不代理用户账号、Cookie、令牌、课程数据。
- 免配置的两个公共 GitHub 代理：`gh-proxy.org` 和 `ghfast.top`，自动模式按两个代理、官方 GitHub Releases 顺序重试；用户也可选择“GitHub 官方源”或“公共代理”模式、关闭跨源故障切换。
- 经过 SHA-256 复核的 HTTP Range 断点续传：只有正确的 206 Content-Range 才允许续写；服务器返回 200 时从头写入；损坏内容不作为已完成安装包。
- 旧版稳定版/Beta 更新偏好兼容，更新下载目录保留已校验安装包缓存；安装由用户退出软件后手动执行。
- **不依赖 R2、SourceForge、自建 CDN、备案或存储桶**，没有任何额外第三方账号配置步骤。

## 保留 rc.35 原有功能
- 完整继承 rc.35 的知到课程切换、进度采样与播放器观测相关修复，以及 rc.34 的学习通、雨课堂、U校园功能；本次不改变原有学习协议或播放上报。

## 验收限制
- 公共代理不保证中国内地速度或长期可用，国内真实网络的下载与回退仍须测试。
- GitHub Releases API 仍是元数据的唯一可信入口，不从公共代理解析未经验证的版本信息。
- 当前没有下载字节百分比或自动安装；必须通过 Python/React/Windows NSIS 全流程测试和主分支正式发布才能对外称为可用版本。
- 仅更新安装包下载传输路径，不修改现有知到、学习通、雨课堂、U校园学习业务逻辑。

版本：`0.1.1-rc.36`。由主分支对应 SHA 的 Windows 发布流程构建并发布，旧版本发布包不可覆盖。
