# 学序 StudyFlow 0.1.1-rc.23｜知到同课并发与课程执行阈值

## 知到同一门课视频并发

- 新配置默认双路，可选择 1–3 路；各视频独立显示名称、本地片段进度和状态，结束后自动补位。
- 支持停止单个运行中或排队项目；原有停止按钮回收整门课的任务进程树。
- 共享课按视频拆分；AI 课程精确到知识点内的具体资源，文章和 PPT 顺序处理。
- 保留选择范围、总视频数、总时长、倍速上限、已完成跳过和错误策略。验证码、平台时间限制等明确阻断条件停止整个队列。
- 修复退出视频的旧百分比持续显示，以及父管道监听导致正常子进程异常退出的问题。

## 刚更新的完成阈值

- 知到每门课独立保存执行目标：可选自动沿用原版课程类型配置，也可自定义 1–100%。
- 并发子进程继承本门课设置的执行目标，不会因拆分视频丢失阈值。
- 雨课堂执行目标按当前学校和课堂范围保存，切换课堂不串配置；没有显式设置时保持 100%。
- 旧配置迁移保留已有阈值与并发数；从未设置过并发的存量配置保持单路，可在课程观看控制中改为双路。
- 执行目标只决定本地任务何时结束，不能替代平台的真实完成状态；课程记录继续以服务器只读核验为准。

## 知到 ZHS 启动可靠性修复

- 修正 ZHS 0.1.5 原版 URL 解析对含特殊字符课程标识的截断问题：优先选用原版可解析的有效路由；必要时由原版按当前账号的数字课程 ID 重新定位；无法解析时明确拒绝错误路由。
- 课程 ZHS 本机参数读取失败时，明确展示原因和重试入口；可经用户确认恢复本课程默认参数，不删除登录 Cookie。
- 切换课程或重新读取参数时，先清理上一课程的暂存值，避免误用；若此前保存的资源选择不可核验，提供显式切回整门课的操作。
- 这些调整仅改善本地控制与进程入口，不修改原版上报协议；任务退出或本地执行阈值仍不代表服务器认可学习记录。

## 保留的界面更新

- 包含主分支已合入的设置弹窗、课程进度展示及统一控件样式调整。
- 更新说明随安装包附带，安装升级后可在应用内查看本次改动。
