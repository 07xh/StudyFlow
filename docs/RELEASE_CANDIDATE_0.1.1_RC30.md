# 学序 StudyFlow 0.1.1-rc.30｜学习通课程布局修复

## 本版更新

- **修复学习通课程页布局**：运行参数、操作按钮恢复成组排列，避免控件挤压或垂直错位。
- **运行概览重排**：运行状态、申报记录、服务端确认、任务数量、运行 ID、当前配置以响应式卡片显示。
- **任务列表优化**：无任务时显示明确的空状态，不再保留大面积空表格；有任务时提供可横向滚动的完整状态列。
- **日志与窗口适配**：运行日志使用折叠区；宽屏、窄窗口与小屏均有专属布局。
- **跨平台组件隔离**：包含此前主分支对知到 ZHS 执行区错误出现在学习通课程页的修复（PR #147）；学习通布局修复为 PR #149。
- **工程化验证**：补充学习通空/有任务两态、响应式 CSS 作用域及集成组件同步的回归测试；不改变其他平台现有运行器接口。

## 功能及验证边界

本版延续 rc.29 已合入的学习通实验性接入，但不将本地任务记录视作已验证的课程完成证据。真实账号课程/章节数据、服务端状态、会话恢复和 Windows 真机界面仍需在本人授权环境中验收。Python、React/浏览器、Windows 构建与安装/升级/卸载验证结果以 GitHub Actions 本次构建记录为准。

## 安装与更新

- 版本：`0.1.1-rc.30`，Windows x64 NSIS 安装包；保留旧版 rc.29，生成新 Tag/Release，不覆盖旧安装包。
- 工作流只在最新 `main` 提交的构建与测试成功后发布，并检查 Release Tag 未指向其他提交。
- 更新通道选择 **Beta** 即可从应用内检查候选版，下载安装包完成 SHA-256 校验后退出学序并手动安装；安装后重启生效。
