# 学序 StudyFlow 0.1.1-rc.21｜知到当前观看内容与进度条

## 本次更新（PR #114）
- 在知到 ZHS 原版播放区突出显示当前视频、PPT、文章等资源的真实识别名称、类型和序号，并为视频本地播放进度增加常驻进度条。
- 有可靠的当前采样时展示播放位置百分比；采样未知、已过期时展示不确定状态，不将未知伪装为 0%。
- 采样过期时保留最后一次识别的资源名称、类型和序号，但明确标记为“上次识别”，不复用旧百分比，也不把上次资源说成正在播放。
- 将低频使用的详细运行诊断默认折叠，改善播放区信息层级；保持视频片段位置与服务器课程完成率语义隔离。
- 增加 React、Rust 对当前资源、过期采样和进度显示的回归测试。

## 保留 rc.20 及既有功能
- 雨课堂旧版 90% 本地阈值统一提升为本次运行 100%，避免未完成课程提前结束；本地任务处理结束仍需服务器只读核验。
- 雨课堂单视频服务器完成标志、原始观看率、只读复核、课堂及学校 ID 保存检查。
- 更新提醒弹窗、真实 GitHub Release 更新说明、安装后首次运行更新日志。
- 知到/雨课堂登录、课程读取、执行器、参数、任务恢复，以及真实服务器核验进度均保留。

## 验证边界
- 仅在主分支版本通过 Python、React/TypeScript、Windows NSIS、干净安装/升级/启动/卸载检查后生成独立预发布版 v0.1.1-rc.21。
- CI 通过不代表用户真实 Windows 账号已验证当前资源进度；需要实际播放、切换资源、停止与采样过期场景验收。
