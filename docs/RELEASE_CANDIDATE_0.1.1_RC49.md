# 学序 StudyFlow 0.1.1-rc.49｜ZHS 单章节多任务并行

## 知到 ZHS 调度
- 当前课程 → 参数设置 → 运行参数，可在「跨章节并行（原模式）」与「单章节内多任务并行」之间切换。
- 新模式对同一章节内的不同资源分配独立执行任务，整门课程共享 1–3 个并发槽位；任务结束或失败后由单一调度器负责回收并补位。
- 优先调度不同章节或不同知识点，保持资源身份独立；旧课程和旧保存配置仍默认原模式，不会自动改变任务行为。
- 支持独立停止资源、异常清理与服务端只读进度核验；不新增心跳发送器、不提高倍速或并发上限。

## 知到扫码登录
- 修复从「账号与连接」打开知到扫码登录时，二维码被设置面板遮挡的问题；扫码弹窗置于顶层，并保留深浅色按钮样式。
- 不变更二维码获取、扫码轮询、账号验证、登录 Cookie 或 ZHS 原版心跳逻辑。

## 沿用 rc.48
- 全局设置中的独立开发者网站介绍及外部入口。
- ZHS 无资源知识点及文字/PPT 资源类型支持、只读进度核验与原有选学/必学设置。

## 检查与限制
- Python、React、Rust、Windows NSIS 构建、安装升级卸载通过自动化检查后，才通过正式发布工作流生成安装包。
- 多路运行的服务器端学习记录仍受平台规则影响，自动化测试不等于真实账号验收成功；不要把本机运行状态误当成平台确认完成。

版本：`0.1.1-rc.49`。
