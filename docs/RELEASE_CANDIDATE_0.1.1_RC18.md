# 学序 StudyFlow 0.1.1-rc.18｜知到与雨课堂断点恢复、进程防重

## 本版新增
- **恢复上次学习任务**：原版任务中断、软件重启后，在首页和运行任务页提示上次未确认结束的任务；用户点击「核验并恢复」后才会尝试重新启动。不会未经确认在后台循环启动任务。
- **保留真实断点**：知到 ZHS 和雨课堂继续使用其原有的服务端学习位置读取逻辑；本次开发不修改平台播放/学习上报算法。
- **恢复前严格核验**：知到核实当前课程及服务器返回的真实进度；雨课堂核实课堂范围、带本机随机密钥的会话标识，并只读检查视频进度。切换账号、失效会话、进度无法核验时拒绝恢复。
- **异常退出防重复**：每个平台增加子进程操作系统互斥锁，降低应用异常退出后再次启动同一原版任务的风险。正常停止和正常退出清理对应任务的恢复提示；**进程退出不代表平台确认学习完成**。
- 恢复记录最长保留 30 天，只保存课程标识、执行参数和本机运行标识，不保存 Cookie、CSRF 或平台密码。

## 雨课堂真实课程进度总览（PR #105）
- 雨课堂首次进入平台时自动只读核验本课程全部视频一次；返回时复用本次运行期已确认的服务器记录，手动刷新才重新全课读取。
- 顶部、课程卡片与首页显示基于服务器已核验视频的完成节数；只有全课视频均有可确认记录时才计算视频完成比例。
- 未完成核验、同名视频无法定位或平台未确认的记录不补零、不伪造官方课程总进度；播放期间只对唯一匹配的当前视频做定向只读复核。
- 保留已合并的任务恢复组件与升级后首次打开的更新说明弹窗，未改动平台学习进度提交逻辑。

## 继承 rc.17 的更新
- 新版本首次启动展示当前版本真实更新说明，支持从多个旧版本升级时查看历史更新内容。
- 雨课堂保留首次进入全课只读核验、后续手动刷新、播放视频时的定向进度核验。
- 保留知到视频/PPT/文章类型显示、章节记录筛选与统一课程详情界面。

## 已有自动化验收与限制
- Python/React/Rust 测试及 Windows NSIS 构建、安装/升级/启动/卸载离线烟测作为本次候选版发布门禁。
- 互斥锁覆盖本版本执行器；旧版遗留子进程以及主进程异常退出的特殊情况还需实际 Windows 设备验证。
- 不能把离线 CI 视为真实账号下恢复学习成功。知到、雨课堂登录、章节进度读取与中断恢复必须使用真实平台会话另行验收。
- 详细技术契约：`docs/TASK_RECOVERY.md`；功能合并来源：PR #104。
