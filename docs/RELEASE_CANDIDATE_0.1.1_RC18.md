# 学序 StudyFlow 0.1.1-rc.18｜雨课堂课程进度与平台总览

## 本次新增与修复
- 雨课堂：修复课程列表仅显示“未核验”、顶部没有选择课程时显示空进度的问题。进入雨课堂平台首页后，在登录有效并成功同步课程的前提下，自动进行首次全课只读核验；后续进入页面复用当前会话的服务器核验缓存。
- 顶部学习平台概览：未选课程时默认显示“全部课程”及平台进度摘要，选择课程后自动切换到课程进度，可再切回“全部课程”。数据未齐全时，显示实际已核验/已完成数量与“总体进度待核验”，不把缺失数据当作 0%。
- 雨课堂课程卡片、顶部和章节详情共用进度核验状态。视频播放期间，仍只对能够唯一匹配的视频做只读服务器进度复核，不因页面切换重复全课扫描。
- 雨课堂视频维度完成率仅在完整扫描且全部视频有服务器确认记录时提供，按真实视频数量加权；**这是已完成视频占比，不是雨课堂官方课程总进度**。
- 知到保留各课程已有的官方/知识点/视频进度口径，顶部平台汇总明确标记为课程进度概览，不伪装成官方总进度。

- Windows 原生浏览器：修复设置页及版本说明弹窗中「GitHub 官方发布页」链接点击后无响应的问题。桌面版通过固定可信地址打开系统默认浏览器；失败时显示可复制的官方链接（PR #101）。

## 延续已有功能
- 保留主分支 #104 双平台任务恢复和异常退出防重功能，以及已发布 rc.17 的升级后首次启动更新说明弹窗。
- 保留两个学习平台的原有登录、课程读取、播放控制、任务中心和章节筛选，不改变服务器上报机制。

## 验收及使用限制
- 发布门禁：合并后的 main 必须通过 Python 回归测试、React 生产构建及 UI/IPC 检查、Windows NSIS 安装包构建，以及安装/升级/启动/卸载测试。只有全部通过才自动创建本次候选版，避免覆盖任何旧版。
- CI 证明程序能够构建并完成离线流程检查，**不能替代真实 Windows 设备、真实雨课堂账号对课程进度显示、服务器核验和播放更新的实机验收**。
- 当平台不返回可信服务器进度时，软件应如实显示“未核验/待核验”，不捏造数值。
