# 学序 StudyFlow 0.1.1-rc.55｜掌握度可靠性与会话性能修复

## 已修复
- 把“本机确实没有知到 Cookie”“服务端会话未能确认”“登录检查异常”区分显示，避免网络波动时错误提示必须重新扫码。
- 掌握度缓存改为当前登录 Cookie 的进程内哈希隔离；点击刷新会主动绕过 90 秒缓存并重新读取分数。
- 修复 `with_mastery=false` 只读目录缺少默认分数字段引起的统计异常。
- 全自动调度统一使用实时掌握度而不是历史最高分判断用户配置的目标分数。
- 保留中断前的试卷标识、问题 ID 及提交标记（不持久化凭证和题目答案）。重新启动后只读确认官方交卷状态、全部判分和掌握度，三项不齐就保护整门课不再自动交卷。
- 全自动处理一个知识点时复用已验证的 ZHS 会话，避免每一道题都重复 CAS 校验；最长两分钟轮换，并在本地 Cookie 改变时停止使用旧会话。
- 在界面显示待核验知识点数量，新增针对缓存隔离、当前分数、旧卷恢复、会话复用和登录切换的回归测试。

## 保持不变
- 四种首轮策略、手动掌握度入口、官方 ZHS 播放器与视频心跳协议均保持不变。
- 不自动重发状态不明的交卷 POST；真实账号是否达到目标分仍以知到服务器为准。

## 验证边界
本地代码及 GitHub CI 可验证程序状态与接口调用约束，不能替代实际 Windows 登录后的线上接口验收。

版本：`0.1.1-rc.55`。
