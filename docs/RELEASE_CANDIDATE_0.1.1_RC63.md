# 学序 StudyFlow v0.1.1-rc.63｜共享题库服务解耦与旧状态清理

## 本次维护

- **通用题目校验独立**：`question_bank` 不再调用首个题库言溪的私有字段校验函数，题干、选项和题型仍遵循相同长度与类型规则。
- **Token 状态元数据安全化**：仅保留约定的检查原因码；即使第三方诊断错误信息混入 Token、URL 或题目，也不会存储或透传到题库列表。
- **通用错误说明**：新增第三方适配器 Token 格式错误的界面提示；不回显敏感内容。
- **过时文档修正**：README 不再把已经合并的 U校园 PR #151 描述为 Draft；题库文档说明 rc.62 的实际整合状态。
- **清理审查记录**：新增 `docs/CODE_CLEANUP_AUDIT_2026_11_22.md`，区分已经清理的旧入口与依然承担兼容任务的原版资源。
- **回归测试**：新增跨题库字段校验独立性、恶意诊断原因过滤以及 UI/IPC 错误映射测试。

## 保留边界

rc.62 的题库中心、批量 Token、自动轮换、可用性和额度查询、旧 `yanxi.dpapi` 数据迁移及课程各平台的实际执行逻辑均保留。本次不触及 ZHS 心跳、官方播放器、任务调度或作业提交协议。

## 验证

Python 单元回归、React 生产构建和 UI/IPC 回归、Windows NSIS 安装/升级/启动/卸载。自动化验证不等于真实账号或第三方题库状态接口的在线验收。
