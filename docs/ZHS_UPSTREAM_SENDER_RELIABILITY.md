# ZHS 0.1.5 原发送器可靠性补丁

## 目标
对原版 AI、Hike、知到共享课程发送状态机定点修复。不会创建额外发送器，不改变请求 URL、数据结构、加密、速度、心跳周期、认证与平台限制。

## 修复
- AI 视频：发送失败立即报告失败，末帧不额外等待；课程汇总不再把未确认资源称作完成。
- Hike 视频：修复到达终点仍循环、错误的取模间隔检测、失败重试过密、服务器返回较小时间导致状态回退，以及末次未确认仍显示完成。
- 共享课程：末次报告失败不再输出完整本地进度；通过 ApiError.code 区分可恢复业务错误，不再解析错误字符串。
- HTTP 成功响应不等于最终记账，结束后仍由学序执行已有服务器只读进度核验。

## 隔离构建
build-sidecar.ps1 先调用 zhs_upstream_patch prepare，在 build/zhs-stage 复制 pip 安装的 zhs==0.1.5 包。四个文件经 pjm314159/zhs v0.1.5 Git blob SHA 校验后进行唯一锚点替换。PyInstaller 采集隔离副本，冻结的 --zhidao-env-check 必须确认四个模块均含补丁标识。
任何源码版本不符、锚点歧义或冻结包不含补丁均使构建失败。旧 ZHSDesktop、pip 安装目录以及 legacy 原始快照不被更改。

## 验收
离线单测检查变更边界、源码门禁、冻结模块标识；仍须 Windows CI、完整 NSIS 安装验证、实际课程与服务器进度只读验收。真实账号实测之前不可认定正式版已经可靠。
