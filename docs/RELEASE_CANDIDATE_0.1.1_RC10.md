# 学序 StudyFlow 0.1.1-rc.10

本候选版本修复 Windows「版本与更新」错误提示过于笼统的问题，保持既有知到、雨课堂执行和课程管理实现不变。

## 更新与下载

- GitHub Release 检查、下载、SHA-256 校验、本地存储各阶段使用独立受控错误码。
- 按故障类别显示具体中文提示：无法连接 GitHub、请求受限、发布数据损坏、缺少校验安装包、下载中断、校验失败、磁盘写入失败、异常跳转。
- 不向前端暴露原始 HTTP 响应、Cookie、文件系统路径或潜在敏感异常信息。
- 只允许本仓库 GitHub Release 中唯一的、带 SHA-256 digest 的 Windows x64 安装包；不执行未经校验的文件，且不会擅自启动安装器。
- 若用户本机访问 GitHub Release 下载网络受限，仍须到官方发布页手动获取安装包；此版本改善识别与排障，不保证修复用户特定网络环境。

## 构建与验证门禁

- 发布前运行 Python 回归测试、React/UI/IPC 检查、完整 Windows NSIS 构建及干净安装、升级、启动、卸载验证。
- 通过 main 分支提交构建后发布为新的 rc.10，不覆盖 rc.9。
- 真实 Windows 电脑上的 GitHub 下载链路及学习平台登录/课程读取仍需实际验收，不能被 CI 替代。
