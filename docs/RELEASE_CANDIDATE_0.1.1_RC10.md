# 学序 StudyFlow 0.1.1-rc.10｜知到资源可见性与观看范围

## 用户实机录屏对应问题
- 旧版仅显示“知识点资源 5/6”和变动的片段百分比，无法区分当前处理视频、文章或 PPT。
- 原版每个视频有自己的片段进度，不能把 3.8% → 0.4% 当作课程整体进度回退。
- 停止后再次执行原版任务会创建新进程，不能宣称支持进程级无缝断点恢复。

## 修复
- 从原版 AI 课程资源模型只读观察资源类型及短名称：视频、课程视频、PPT、文章、其他资源；不增加独立发送器。
- AI 课程按课程保存“全部、仅视频、仅文章/PPT”运行范围；共享课保留原版视频路径。
- Windows Tauri 校验本次执行令牌、时效、资源名称和类型后，将资源信息传给 UI。
- 将当前视频片段位置、资源序号与服务器核验进度分开，并保留不含资源类型字段的旧版片段快照显示。
- 保留 rc.9 的安全登录失败诊断、LightC 设置弹窗和主分支已经合并的 UI 清理；本次不修改原版 ZHS 心跳发送速度或算法。
- Python、Node/React、Windows Rust/NSIS、安装/升级/卸载测试作为发布门禁。

## 限制
- 上述百分比只是原版当前视频片段的本地输出，不能直接反推出实际观看速度或校方记账结果。
- 停止后再启动仍会新建原版进程；本版不实现伪暂停/伪续播。
- 必须由实际 Windows 账号核验最新课程进度、资源类型与资源标题，CI 通过不等同真实平台验收。
