# 学序 StudyFlow 0.1.1-rc.14｜更新检查及安装状态纠正

本次 Windows RC 版本保留知到、雨课堂课程和进度读取功能，修复更新检查的误导性反馈。

## 更新模块
- 新安装的默认更新通道改为 Beta，以发现当前 RC 预发布版本；保留用户主动保存的通道设置。
- 稳定版通道没有新版本时提供切换 Beta 的提示，而不是声称已安装最新版。
- GitHub HTTP 403 只有在限流响应头确认时才显示「限流」，429 仍视为限流，其他 403 视为访问失败。
- 检查失败不清除本会话已校验下载安装包的显示状态。
- 明确显示当前运行版本、下载不等于安装和官方发布页。
- 保留受信任的 HTTPS 下载地址、SHA-256 校验、原子写入和不自动执行安装程序。

## 发布验收
- Python 回归测试覆盖 403、429、503、失败下载不落盘。
- 前端回归测试覆盖 Beta 默认通道和下载状态保留。
- PR Windows CI、主分支 Windows 构建及 NSIS 干净安装、升级、启动、卸载通过后发布。
- 实机网络与用户完成安装仍需 Windows 电脑确认；CI 不能代替实际安装状态。
