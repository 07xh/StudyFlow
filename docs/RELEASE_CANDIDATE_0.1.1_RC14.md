# 学序 StudyFlow 0.1.1-rc.14｜雨课堂全课核验与响应式布局修复

## 本版变化
- 雨课堂课程详情一次触发后，按原有每批最多 8 节的服务端只读接口，顺序读取当前课程全部视频记录；不再需要逐批手动点击。
- 途中某批失败时已核验的真实进度保留；可从中断位置继续核验，不将失败或未核验项目标成 0% 或已完成。
- 修复章节进度继承旧横排容器导致的布局挤压，改为全宽纵向结构；三列统计按窄窗口响应，筛选与章节行可换行阅读。
- 前端回归覆盖 63 节视频的八批顺序读取、失败分页续查、进度真实性和筛选；保留 rc.13 知到进度同步修复及既有雨课堂/知到功能。
- 不改动平台登录、原版播放器、心跳生成或提交接口。

## 发布门禁与限制
- GitHub Actions 必须在同一 main 提交上完成 Python/React UI 测试、Windows NSIS 打包和安装/升级/启动/卸载核验，再发布独立 rc.14 安装包，不覆盖 rc.13。
- 自动化测试使用受控响应验证代码契约，不能代替用户 Windows 真实账号的雨课堂课程、章节及服务器进度字段核验。
- 仅已核验的视频服务端记录显示百分比；未核验不等于未完成，PPT/图文不虚构视频进度。
