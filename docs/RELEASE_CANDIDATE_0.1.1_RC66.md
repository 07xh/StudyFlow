# StudyFlow v0.1.1-rc.66｜四平台进度稳定性、普通查题与共享题库状态同步

## 本版重点
此版本整合 rc.65 之后已合并到 main 的进度核验、调度稳定性、普通查题、共享题库与知到掌握度 UI 维护。**知到和雨课堂的原版心跳、播放协议与发送节奏均保持不变。** 已有用户反馈：后续优化版本实际测试后，这两个平台的服务器学习进度仍然正常更新；这不等同于其他平台的真实账号端到端验收。

## 四平台稳定性修复
### 知到 ZHS
- **队列诊断容错**：章节进度快照或诊断文件中如果出现合法 JSON 但不是对象（如 `[]`、`null`），只丢弃该次观测，不再把解析异常传给章节调度器（#233）。
- **知识点详情防串位**：快速切换知识点、课程或运行轮次，以及收起详情时，较早返回的服务器只读结果、错误与加载状态不再覆盖当前页面（#243）。
- 继续区分本地视频片段位置、运行状态与服务器已核验进度；不重写原版心跳。

### 雨课堂
- **批次统计隔离**：每批原版播放日志重新初始化任务状态、运行路数、百分比及统计，防止上一批残留污染本批（#231）。
- **只读元数据边界**：课程数据读取拒绝登录重定向与非 200 响应，不误当已验证课程（#232）。
- **完成状态准确性**：服务器显式返回不合法的 `completed` 值时，不再因为 `rate=100%` 就认定视频完成；只有旧接口确实不提供该字段，才使用原有完整播放率回退（#238）。
- 保留雨课堂原版执行器和已有正常的服务器进度更新行为。

### 学习通
- **断点恢复修正**：服务器最新视频时长短于本地断点时，恢复位置不再越过有效时长（#229）。
- **服务器只读解析容错**：异常浮点、非有限播放位置、超大数字和畸形 HTTP 状态不再使校准出现无限循环、溢出或无效进度（#242）。
- **任务终态稳定**：启动前只读校准、退出后服务器回读失败或返回错误结构时，不再让异常中断任务结束记录或污染服务器确认状态（#244）。
- 本地运行进度与服务器最终确认继续分开显示。

### U校园
- **停止状态可信**：后台工作线程尚未真正退出时返回“停止中”，不再立即误报已停止（#234）。
- **只读请求不阻塞设置**：读取服务器进度时可并行禁用监控或切换账号、课程；旧请求结果会被丢弃，并避免同时重复发起查询（#235）。
- **系统校时恢复**：Windows 时钟回拨后，监控可恢复只读服务器查询，并继续遵循正常 60 秒间隔（#237）。
- **进度值校验**：非有限的 `pass` 数值不能被认定为服务器已完成（#240）。
- **监控界面防串位**：课程、单元切换后，不再使用已过期的配置返回、首次查询或手动刷新结果覆盖当前页面（#245）。
- U校园服务器状态核验与实验性本地事件仍分别呈现，不能仅凭本机任务结束推断服务器学习记录。

## 题库、Token 与掌握度界面
- **普通查题防串题**：题干、题型或选项变化即清理旧答案；过期题库列表、晚返回答案和收起后重开的旧错误不会覆盖新题，已发生查询的真实余额仍可同步（#241）。
- **题库余额联动**：普通查询返回可验证的剩余次数后，已打开的题库汇总与掌握度 UI 同步更新，而不是静默保留旧余额（#236）。
- **状态竞争处理**：Token 新增、切换、删除及并行检查时，旧列表响应不能反向覆盖新配置；对题库与掌握度页面保持一致的状态失效和刷新规则（#239，及 #220–#230 相关更新）。
- **知到掌握度 UI**：完善任务启动前的当前工作线程状态检查、课程范围切换、状态过期提示、参数校验、任务处理数与服务器核验数分开展示；Token 列表变更后避免继续使用已不存在的选择（#220–#230 中的相关更新）。
- 继续保留 rc.61–rc.65 已实现的共享题库、多 Token 安全保存与轮换、单独余额检测、来源官网链接和离线开源许可证阅读。
