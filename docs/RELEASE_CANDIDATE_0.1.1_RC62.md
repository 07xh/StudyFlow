# StudyFlow v0.1.1-rc.62｜题库中心重构与旧代码清理

## 本次整理
- **题库中心重构**：设置页只展示各来源、Token 数量、已识别可用数量、已知总余量与覆盖条数；手动搜题表单撤出设置，实际查题入口及后端接口保持可用。
- **统一检测**：提供一键逐条检测全部 Token 的入口；需另行确认才能尝试获取可能消耗额度的余额数据。未知余量不算作 0。
- **来源管理二级浮窗**：逐题库管理 Token 批量导入、轮流使用、默认选择及删除；所有题库卡片附 HTTPS 官网链接，系统默认浏览器打开。后续新增题库通过注册表自动扩展。
- **统一题库入口**：移除历史言溪专用保存/清空/查询 IPC 和废弃前端 helper。查题、批量 Token 导入、自动选择、有效性检测、剩余额度全部由统一题库接口负责。
- **避免双份凭据**：言溪适配器不能再单独写入 Token 文件或隐式从旧文件取凭据。保留旧版 `yanxi.dpapi` 的一次性只读迁移，只有新保险库成功写入后才尝试删除旧文件；不会静默丢失旧 Token。
- **消除重复源码**：移除 `integration/frontend/` 下的学习通心跳面板 TSX/CSS 副本；现行 `frontend/src/components/` 内组件完整保留。
- **错误提示修正**：题库与服务错误不再混进更新失败映射，用户可看到更对应的 Token、额度及连接异常提示。
- **测试收敛**：同步 Python 离线迁移/错误边界测试、React 旧入口防回归测试及 Windows 原有构建测试。

## 保持不变
- rc.61 的题库批量 Token 管理、轮流选择、余量读取和知到掌握度工作台功能继续保留。
- 知到 ZHS 原版任务、心跳、官方播放器、雨课堂原版任务、学习通实际运行组件、U校园模块均未在本轮改动中重写。
- 历史发布说明和 `legacy/zhidao`、`legacy/yuketang` 中仍被使用的原版资源继续保留。
