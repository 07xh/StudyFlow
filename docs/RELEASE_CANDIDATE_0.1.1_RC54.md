# 学序 StudyFlow 0.1.1-rc.54｜减少 Windows 客户端卡顿和掉帧

## 轮询与 React 渲染优化
- 全局任务状态每 2 秒查询保持不变，但运行器状态、任务标识和连接状态完全相同时，保留原来的 React 状态引用，避免触发整个课程工作台重复渲染。
- 知到 ZHS/雨课堂原版任务面板、知到官方播放器使用深度状态快照比较：真实进度、退出状态、故障和服务器证据变化仍正常更新；无变化的轮询不重新绘制任务行、视频和并发槽位。
- AI 掌握度面板的只读轮询增加单请求并发保护和 15 秒超时；耗时的 Python IPC 不再每 2.5 秒叠加一次。只变化后台更新时间戳时跳过列表重绘，任务及分数变化仍实时更新。

## WebView 渲染优化
- 首页/课程主区域、固定侧栏和顶部状态栏原本用 22–24px 的大面积 backdrop-filter；这些面板背景几乎不透明，已改为仅保留原有渐变与阴影，减少持续 GPU 合成负担。
- 知到加载中的进度条从每帧修改 left 改为 transform 位移动画，减少布局与重绘操作；保留原速度和“减少动态效果”偏好。

## 已验证范围与注意事项
- 新增嵌套快照比较、全局轮询无变化不重渲染、掌握度单请求轮询、WebView 静态玻璃效果回归测试。
- 保留 rc.53 的知到登录路径、全自动掌握度启动入口、常驻 Python Sidecar、真实服务器核验及所有原版视频心跳行为。
- 本次是具体性能热点的静态修复和自动化回归，未取得用户电脑的 FPS/CPU/GPU 实测数据；无法承诺任何硬件环境下彻底消除所有卡顿。
