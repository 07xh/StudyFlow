# StudyFlow 0.1.1-rc.58｜通用题库中心与多 Token

## 新功能
- 将 rc.57 言溪专用搜题面板升级为**平台无关的共享题库服务**。
- 「设置 → 题库与搜题」可管理多个题库提供方的 Token；言溪是首个正式适配的来源。
- 同一题库支持最多 20 条 Token：自定义备注、加密保存、切换默认、删除；不会自动轮换消耗额度。
- 当前有真实练习题数据的知到「AI 掌握度」栏目已接入：每道题下有「题库查题」，并能在查询前选择题库及 Token。
- 提供面向其他作业和习题模块的统一 `questionbank.query` IPC，支持题干、题型与选项的标准化结构；以后接入学习通、雨课堂等模块无需修改题库管理面板。
- Windows DPAPI 加密新的多 Token 保险库，首次读取安全迁移 rc.57 已保存的旧言溪 Token。

## 与原来不同
- 原言溪专属面板已替换为全局题库管理及单题内嵌查题控件。
- 手动查题还保留，但不是惟一入口；多个学习/作业模块均可调用同一服务。
- 题库服务仅返回外部参考内容，不自动填写、交卷，也不会覆盖官方判分的本地答案记录。
- 保持知到视频心跳、现有自动掌握度调度及其他平台运行逻辑不变。

## 使用
1. 打开学序 →「设置 → 题库与搜题」，选择言溪题库。
2. 添加一条或多条本人 Token，填写备注，并选择使用哪一条。
3. 打开知到 AI 掌握度练习卷，在任一道题下点击「题库查题」→ 选择来源和 Token → 查询本题。
4. 将来其他平台有题目展示页时，同样可使用此通用查题组件。

## 验收说明
- 无需 Cloudflare，由 Windows EXE 内置 Python Sidecar 直连。
- 代码与离线测试不使用真实用户 Token；实际言溪查询是否成功、额度、计费和接口格式需本人实测。
- 当前实现的是**可复用题库调用接口**，并非已把所有平台普通作业页面都接好；未接入的作业栏目仍需真实题目数据/界面支持。
- PR 的 Python、React、Tauri、NSIS 回归状态以 GitHub CI 为准。
