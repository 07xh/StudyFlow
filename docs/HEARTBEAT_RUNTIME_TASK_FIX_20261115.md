# 学序心跳任务管理可靠性修复（2026-11-15）

## 范围

基于当前 `main` 的 rc.6 源码移植，不覆盖更早压缩包的整套 UI 或原版心跳算法。

- `legacy_start`、`legacy_status`、`legacy_stop` 在 Tauri 阻塞任务池调度，保留 run ID 验证、进程树停止、限时任务以及 rc.6 隐私安全诊断。
- React 轮询失败时保留最后一次任务身份，用于停止前重新查询 run ID；同时隐藏已失效进度、退出诊断，阻止状态未知时再次启动。
- 轮询成功后恢复正常状态显示，保留停止提示，避免退出状态轮询清空反馈。
- 对新任务调度错误给出可读提示，补充 UI/源码静态回归测试。
- Python 项目版本元数据与既有 rc.6 候选版本对齐。

## 明确未修改

不改知到原版 ZHS 0.1.5、雨课堂原版 `main.py`、既有心跳发送协议、课程接口、学习记录或服务器进度算法。**本地显示进度、退出码、日志均不构成服务器完成证明。**

## 发布与验收门禁

合并前至少验证：Python `pytest`、React `npm run build && npm test`、Windows Rust 编译与 NSIS 真实打包和安装/卸载测试。合并后仍需使用真实 Windows 学习环境确认开始、停止、切换课程、进程树清理、轮询断线恢复，以及只读服务器进度核验。

本 PR 通过本地静态检查和 GitHub Actions 不代表真实账号业务验证已完成，也不能把压缩包作为已验证的 EXE 安装程序。
