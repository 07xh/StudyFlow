# 学序 StudyFlow 0.1.1-rc.28｜LightC 风格全局设置中心

## 本版新增与优化

- **全局设置浮层**：点击标题栏「设置」后，直接覆盖在当前工作台上打开设置中心，不再切换主页面；原课程、任务和滚动上下文保留。
- **LightC 风格二级窗口**：居中浮层、背景遮罩、左侧分类导航与右侧内容、轻量开关动画；设置分类切换不另外弹出窗口。
- **导航尺寸**：左侧导航支持拖拽调宽、键盘方向键调宽并保存视觉布局偏好；窄窗口改用横向分类导航。
- **设置与更新**：完整迁移通用外观、版本与更新、关于与开源；更新面板切换分类时保留已下载状态，移除重复标题。
- **交互细节**：支持 Esc、点击遮罩、右上关闭按钮；关闭后恢复焦点；嵌套的隐私/开源文档可以单独关闭。
- **回归验证**：增加浏览器、最小窗口及键盘交互检查；移除失效的整页设置路由和导航样式。

## 保持不变

- 搜索与筛选：课程、章节的搜索、筛选和清空操作没有修改。
- 知到与雨课堂：账号、参数弹窗、真实任务进度、播放执行与平台核验逻辑不因本次设置改造而变化。
