# 知到 UI → 学序 StudyFlow 迁移记录（2026-11-14）

## 迁移来源

- 源仓库：`07xh/zhidao-assistant`
- 已审查的 WPF UI 基线：`53c92446d40b2cd1732c9aa1884d9f3b3a3fe55a`（动态课程卡片、二维码刷新、会话确认、深色模式和缩放布局）
- 目标仓库：`07xh/StudyFlow`（React + Tauri 2、Python sidecar）
- LightC 2.18.3 仅作为视觉交互参考。新 UI 不含其 Source Available 专有限制组件和素材。

## 已迁移到统一界面

1. 自有 React 动态课程卡片：知到/雨课堂平台标签、课程类型、未核验/历史缓存/服务器已核验三态、长标题、自适应列数。
2. 进度严格以服务器证据为准：必须同时满足 `progress_evidence = server_verified`、有效 `verified_at`、非 stale 和合法百分比才显示进度条。当前后端没有核验进度映射，因此不会虚构进度条。
3. 知到登录引导：扫码入口仍调用原版 WPF 登录窗口，保留原版二维码刷新、临时图片清理和服务端验证；直接输入 Cookie/文件导入仍在旧版软件中，新 UI 的相关入口暂时禁用，绝不收集浏览器凭据。
4. 深色/浅色主题偏好仅存储本地外观标记；布局支持窄侧栏、单列课程、课程筛选和查看课程信息。
5. 由学序既有 Tauri IPC 调用 Python 真实服务端状态与课程读取接口；不存在浏览器模拟服务或预填示例课程。
6. 保留当前主分支中已经实现的雨课堂会话配置/清理、真实章节视频和 Tauri/NSIS 打包来源。

## 已修复的知到数据读取问题

旧版 `zhidao_only.py` 位于扁平安装目录 `%LOCALAPPDATA%\\ZHSDesktop\\zhidao_only.py`，不是 `payload/` 子目录；现有学序主分支已使用正确路径。此轮补充：
- 通过上游 `progress_key` 基于课程类型、课程身份、教学班生成稳定不可逆标识，避免不同 AI 教学班碰撞，不把共享课路由标识写入前端显示。
- 保留 `course_type`、`stale`，不再把历史课程误显示为新核验数据。
- 不改动原版课程同步的 Session 指纹 HMAC、失败来源拦截和会话有效性核验。
