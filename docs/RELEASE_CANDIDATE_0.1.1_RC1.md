# 学序 StudyFlow 0.1.1-rc.1（候选版）

此版本用于验证知到 ZHS 0.1.5 发送状态管理、服务器进度核验与登录状态可靠性。**它不是正式发布版本，不能将本地进度视为校方已确认的完成记录。**

## 主要变化
- 在 Windows 打包时使用上游固定版本 ZHS 0.1.5 的隔离源文件副本，对发送失败、终点循环及错误分类做可靠性修复；不更改平台协议或请求格式。
- 服务器进度只读核验可重试，并避免重复状态请求导致竞态。
- 将 #61 的认证会话关联、验证时间戳和缓存证据校验合入；修正 #63 的登录探测成功码判断。
- 原安装目录、原始备份以及旧 ZHSDesktop 保持不变。

## 发布门槛
1. 提交上的 Python 回归、React / TypeScript、浏览器 UI 测试通过。
2. GitHub Windows CI 构建与 NSIS 清洁安装/升级/启动/卸载通过。
3. 运行时检查确保 4 个发送可靠性补丁模块实际包含在冻结 EXE。
4. 实际账号完成登录、课程读取、停止控制和服务端只读进度核验。未执行这项前，只可称为 CI 验证候选包。

## 已知未合并工作
- #64 知到观看参数/范围功能仍处于 Draft，独立验收后再整合。
- #51、#55 为旧版 UI 分支，和现有主线有冲突，不应直接覆盖新布局。

安装包发布后以构建 SHA 与包内版本共同验证来源，避免误把旧版 0.1.0 文件当成更新。
