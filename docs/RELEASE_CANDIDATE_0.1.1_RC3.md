# 学序 StudyFlow 0.1.1-rc.3 · LightC 桌面布局整理

这是 Windows 候选版；自动化 CI 和安装测试通过不等于真实学习账号、播放或服务端进度的端到端验收通过。

## 本次调整
- 独立的第一行窗口标题栏：学序名称、全局设置、最小化、最大化/还原、关闭；Tauri Windows 窗口使用自定义无边框标题栏并保留拖动。
- 第二行固定展示当前平台和当前课程的服务器核验总进度，未获取真实进度时显示「—」，不伪造百分比。
- 左侧紧凑常驻导航与课程内容分离滚动，顶部状态栏不因内容滚动改变位置。
- 在知到和雨课堂平台页面右对齐一行显示「参数设置、打开课程列表、同步课程列表」，窄窗口不自动换到第二行。
- 平台默认参数移入独立设置视图；知到保留已有播放配置/批量核验/数据维护，雨课堂保留原版参数；主页面保留课程和任务入口。
- 新增 React 静态与多宽度浏览器布局回归测试。

## 不变范围
- 不重新实现平台登录、课程读取、雨课堂原版执行器或 ZHS 心跳逻辑。
- 不将本机任务状态、运行日志或本地模拟观看进度标记为服务器确认的学习完成。
- 保留旧版安装及用户数据，升级安装应执行独立验收。

## 发布门槛
- Python 测试、前端构建及 UI/IPC 测试、浏览器布局检查、Windows NSIS 构建、清洁安装/升级/卸载测试均应通过后再发布本候选版。
- 实际 Windows 电脑上的标题栏拖动、最小化/最大化/关闭和两平台实际登录、读取、任务操作还需真机复测。
