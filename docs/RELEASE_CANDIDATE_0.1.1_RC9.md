# 学序 StudyFlow 0.1.1-rc.9

此版本为 Windows 预发布候选版，整合课程播放工作台、平台设置分层、雨课堂只读章节列表及知到原版登录诊断。\n
## 课程与界面
- **课程详情以播放操作为主**：进入课程即可看到现有执行器的启动、停止和状态查询，不再需要打开“当前课程任务”折叠区。
- **LightC 风格的二级设置弹窗**：账号与连接、播放参数、高级管理和日志/诊断与课程工作台分离；设置操作不替换当前课程页面。
- **章节与视频**：雨课堂进入选中课堂后只读读取真实章节与视频，检查课程归属，按章节展示；知到保留现有真实章节和知识点记录。
- 课程总进度、单视频本地运行输出和服务器核验结果继续分别标识；本地日志或退出码不等于平台确认完成。
- **雨课堂原版仍按已配置的课堂范围批量运行**，不是精确到选中课程的播放控制；本次不改变执行范围协议。

## 知到 ZHS 原版诊断
- 延续 rc.8 的 Windows 用户主目录与 CLI 退出阶段分类修复。
- 新增 ZHS 0.1.5 会话预检细分：本机 Cookie 无法恢复、服务器判定会话过期、服务器校验暂不可用。
- Python 在原版 CLI 会话预检调用期间仅观察分类结果，不改变网络请求、输入参数、返回值、异常传播、进度或平台记录。
- Rust 只接受固定诊断代码；前端给出不含 Cookie、原始异常、课程地址等敏感内容的排查建议。
- 不修改原版心跳算法、服务器上报方式、验证码限制或现有 Cookie。

## 自动化验收和剩余门禁
- GitHub Actions 验证 Python 回归测试、React 构建与 UI/IPC 测试、浏览器布局检查、Rust/Windows NSIS 完整打包，以及干净安装、升级、启动和卸载。
- **真实账号验收仍需在用户 Windows 电脑上完成**：平台连接、雨课堂章节读取、知到任务启动与停止、会话预检诊断和服务器进度核验。CI 不能替代真实平台确认。
- 本 rc.9 应由通过构建的 `main` 提交发布，不能覆盖此前 `rc.8` Release；发布安装包须与对应 GitHub Actions 提交一致。
