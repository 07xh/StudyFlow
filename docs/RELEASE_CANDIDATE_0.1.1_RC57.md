# StudyFlow 0.1.1-rc.57｜言溪题库 Windows 本地 Token 搜题

## 新增
- 增加「全局设置 → 题库与搜题」：可本地保存、更换、清除言溪题库 Token，并手动查询参考答案。
- 知到「AI 掌握度」练习页面增加言溪题库折叠入口，可从当前练习卷选择题目，自动填入题干、选项、题型，主动发起单题搜题。
- 查询固定 HTTPS 地址 `https://tk.enncy.cn/query`，由已打包的 Python Sidecar 直连，无需 Cloudflare、外部 Python 环境或额外窗口。
- Token 由 Windows 用户级 DPAPI 加密保存；状态接口只返回是否已配置，IPC 拒绝无效入参。
- 显示接口可选的剩余查询次数，并明确提示此结果属于第三方参考答案。

## 修复与可靠性
- 区分未命中、Token 失效、次数不足、限流、网络错误、返回格式异常；不会将「未找到答案」等服务端提示误标为正确答案。
- 对固定上游请求禁用 HTTP 重定向，不记录包含 Token 的 URL，避免敏感参数被转发。
- 添加离线查询、DPAPI 存储、IPC 与 React 交互测试。PR #204 的基础版本已经通过 Python、UI 与 Windows NSIS 验证。
- 不修改既有知到官方学习心跳、自动掌握度调度、已验证 SQLite 答案库或其他平台。

## 使用
1. 打开学序 Windows EXE → 设置 → 题库与搜题。
2. 从言溪用户控制台获取本人合法 Token，保存到本机。
3. 输入题干或在知到掌握度练习页选择一题，点击「查询参考答案 / 验证连接」。
4. 核对题库返回内容与题型；查询可能扣除言溪额度。

## 限制与验收边界
- 第三方题库回答仅用于个人查阅，不会自动替用户填入、保存、交卷，也不能作为知到官方判分凭证。
- 使用公开适配器支持的 GET 接口，请求 URL 会被言溪服务器接收；不存入本地日志。
- 没有真实用户 Token 的第三方实测数据，需在已安装 rc.57 的 Windows 设备上验收账号有效性、费用和返回格式。
- 该能力仅适用于 Windows 桌面 EXE，不适用于无 DPAPI 的浏览器预览。

版本：`0.1.1-rc.57`。
