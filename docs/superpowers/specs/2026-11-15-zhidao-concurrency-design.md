# 知到同课程视频并发

用户已批准：同一门课程内独立视频队列，默认 2 路，数量可设置；逐视频名称、进度、状态；结束自动补位；跳过已完成；单独停止及全部停止；平台返回才是完成证据。

## 实现选择

选择独立子进程，复用当前打包的 ZHS 发送实现。线程方案会共享现有 CLI 包装、标准输出和当前资源状态，故不采用。课程级监督进程继续持有平台互斥锁，不开放跨课程并发。

## 契约

- `concurrency` 默认 2，范围 1–3。旧六字段设置迁移为单路，避免升级后无提示改变已有任务；新配置默认双路。
- 监督进程从当前会话实时目录生成唯一目标。共享课按 videoId；AI 按 knowledgeId + resourcesUid，不能把一个知识点当作一个视频。
- 文章/PPT等资源独占执行；视频最多按设置并发。保留倍速上限、总视频数、总时长、选学、选择范围、异常停止策略。
- 每个子进程重新读取当前课程和服务端资源状态，绑定一个精确目标。子进程有独立采样令牌；监督进程每秒原子发布队列状态。父进程退出导致子进程标准输入关闭，子进程立即退出。
- 单视频停止请求绑定当前总任务 runId 与当前行 ID；旧任务请求不能操作新任务。总停止回收完整进程树。
- 子进程退出 0 只显示“本轮结束，待核验”；不推断平台完成。过期采样隐藏数值。
- 并发服务端记账尚未实测；不能用离线测试或打包成功声称平台支持并发。

## 验收

真实本地子进程验证并发上限、唯一目标、自动补位、失败隔离、异常停止、单项停止、父死子停；模型夹具验证实时目标拆分；设置迁移/边界/IPC 与 UI 行为回归。执行完整 Python、React 测试与生产构建；Windows 打包由 PR CI 验证。真实账号验收独立记录。
