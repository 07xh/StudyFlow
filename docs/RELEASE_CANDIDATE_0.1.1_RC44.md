# 学序 StudyFlow 0.1.1-rc.44｜知到隔天恢复与全进度停更修复

## 修复范围
- 在 rc.43 的 ZHS 多视频采样、暂停/答题阶段诊断基础上，继续修复长时间闲置后的状态恢复。
- Windows 软件重新获得焦点且上次平台登录检查超过 5 分钟时，重新核验真实连接状态；异步旧结果不覆盖新会话。
- ZHS 播放任务每 2 秒的只读状态轮询增加 15 秒超时释放，避免休眠期间卡住的 IPC 调用永久阻塞全部进度条。
- App 级服务器进度自动核验按会话生命周期隔离，旧课程的悬挂请求不阻塞新课程。
- 章节进度缓存超过 5 分钟时，进入课程后按需重新核验；如 App 级自动核验已开启，则由其统一负责，避免重复读取。
- 补充章节过期缓存、重复核验、恢复登录、任务状态轮询超时等回归测试。

## 边界与验收
- 本版本的 UI 数值只来自真实的只读采样与平台进度查询，绝不从本地计时生成视频百分比。
- 不修改 ZHS 0.1.5 原版学习心跳、发送协议、播放执行算法，也不清除已登录凭据。
- 以 Python、React/IPC、Windows NSIS 构建及安装升级测试通过作为合并发布门槛。
- 真正的 Windows 隔天启动、当前账号网络环境与服务器学习记录仍需现场验收，CI 成功不代表服务端已确认学习完成。

版本：`0.1.1-rc.44`。
