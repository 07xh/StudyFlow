# 学序 StudyFlow 0.1.1-rc.5 · 各学习平台独立课程首页

这是 Windows 候选版，整合 PR #71 的导航去重与 PR #72 的完整课程主页改造。

## 页面与交互
- 学习平台导航保留知到、雨课堂；不再提供独立的「课程中心」一级导航。
- 进入知到或雨课堂时直接打开**该平台完整课程列表页面**，不在列表下方堆叠平台账号、课堂范围及批量运行面板。
- 各平台课程搜索相互隔离；点击课程后进入该门课程的详情工作区，可返回对应平台课程列表。
- 知到沿用已有官方播放器、ZHS 原版观看控制、章节进度、服务器核验与课程操作记录，不重写运行器。
- 雨课堂课程详情沿用原版播放配置和任务入口，明确显示执行器按**已保存的课堂范围**运行，当前选课不会将批量任务自动约束为单门课程。
- 平台账号与连接、默认参数、知到批量核验及雨课堂课堂范围管理移到平台独立管理视图，课程首页提供入口。

## 保留的底线
- 平台读取仅展示真实同步课程，未登录或无数据时保留空状态；不注入模拟课程、虚构成绩或进度。
- 服务器核验进度与本地观察/任务状态保持区分；不将执行器运行结果视为服务器确认完成。
- 不改知到、雨课堂现有登录、Python sidecar、心跳或执行协议。
- 不覆盖或修改旧 Release；本次为单独版本，并由 GitHub Actions 通过构建后创建。

## 验收与安装
- 候选版发布前必须通过 Python、React/UI/IPC、浏览器多窗口宽度以及 Windows NSIS 构建、安装/升级/卸载自动化测试。
- Windows 真实账号仍需验收登录、课程同步、点击课程、设置和任务停止；CI 不代表已完成真实账号端到端验收。
- 下载 `StudyFlow_0.1.1-rc.5_x64-setup.exe` 后可在保留用户数据的前提下升级安装。
- 应用内预发布更新需在「设置 → 版本与更新」选择 **Beta** 通道；稳定通道不提供该预发布版本。
