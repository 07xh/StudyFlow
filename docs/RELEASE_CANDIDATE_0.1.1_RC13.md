# 学序 StudyFlow 0.1.1-rc.13｜知到真实进度同步修复

## 本次候选版
- 将 PR #88 和 #86 的知到进度修复整合至 `main`：课程详情自动只读核验、返回窗口刷新、同一会话内较旧请求不能覆盖较新服务器核验数据。
- 智慧课程优先使用已校验的服务器 `schedule` 学习进度；缺失或无效时，明确显示“满进度知识点占比”，不混淆掌握度与官方课程进度。
- 显示进度来源、核验时间及同步失败状态；修复章节进度刷新闪烁和失败状态处理。
- 保留知到与雨课堂既有功能，不修改原版 ZHS 进度上报逻辑。

## 质量门禁
本版本仅在同一 `main` 提交的 React/IPC 回归、Windows NSIS 打包与完整安装/升级/启动/卸载校验全部成功后，由 GitHub Actions 自动创建预发布。
**离线 CI 不代表真实知到账号验收通过**：请在自己的 Windows 电脑、同一账号和课程/教学班中核对官方 App 进度，确认返回值和时间一致后再视为真实服务端对齐完成。

> 0.1.1-rc.12 在进度修复合并前发布，不包含此次修复；不要将旧安装包重命名或替换为 rc.13。
