# 学序 StudyFlow 0.1.1-rc.15｜知到 × 雨课堂双平台课程界面融合

## 本次界面优化
- 不再让雨课堂单向模仿知到：抽取共享课程章节视图组件，统一明暗主题、卡片、层级、间距及窄窗口响应。
- 知到：智慧课程知识点 / 共享课程视频按真实章节或主题折叠；顶部集中展示已读取数量、服务端记录完成情况与数据来源。
- 雨课堂：保留自动全课逐批只读核验、失败后续查与逐视频进度，增加与知到相同的章节筛选、放大镜搜索及四态数量统计。
- 两个平台统一「全部 / 待完成 / 已完成 / 未核验」状态筛选、章节选择、展开全部 / 收起全部以及搜索关键词匹配；不再默认占据长列表页面。
- 修复 Rain Classroom 99.999% 被四舍五入显示成 100.0% 的误导：服务端未确认完成时不显示满百分比。
- 知到智慧课程完成标记与数值百分比缺失时区别处理，不把明确完成的知识点显示成未核验。
- 继续保留 rc.14 更新检查修复、rc.13 知到真实进度同步及已有平台业务功能。

## 构建和真实性门禁
- 只有 #97 的双平台 UI 回归、Windows NSIS 安装/升级/启动/卸载检查通过并合入 main，再合并此版本 PR。
- 版本发布由同一 main 提交上的 Windows 安装包与前端回归双门禁决定；已有 release 不得覆盖。
- 离线 CI 验证的是软件逻辑和打包，并非真实知到/雨课堂账号已完成服务器核验。用户 Windows 真机仍须确认课程内容与进度来源。
- 不改动两平台原有登录、播放、心跳和进度提交逻辑。
