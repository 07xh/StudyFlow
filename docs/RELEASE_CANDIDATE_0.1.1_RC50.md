# 学序 StudyFlow 0.1.1-rc.50｜知到 AI 掌握度习题

## 知到 AI 掌握度
- 课程工作台新增「AI 掌握度」栏目：按知识点列出当前掌握度、档位与学习进度，未达标的知识点单独计数。
- 直接在栏目内答题：单选、多选、填空、判断四种题型都可作答，保存后可逐题回看，提交后才计分。
- 提交后展示**本轮正确率**、提交前后的掌握度变化、每题对错与官方解析，并明确区分"本轮得分"与"历史最高掌握度"。
- 支持"再练一轮"：每一轮都是服务端新建的卷（新卷号、新卷面），不会覆盖历史最高掌握度。
- 刷新页面可恢复未提交的一轮，已保存的答案自动回填并标记为已保存，不会重复写入。
- 掌握度通过只读接口读取，仅浏览不会新建试卷、不写任何服务端数据。

## 定位与边界
- 掌握度习题是知识点课后练习，不是考试：没有倒计时、没有监考、没有考试安排。底层 URL 中的 `exam` 只是智慧树服务端的命名习惯。
- 只复用已授权的知到登录态，不启动浏览器、不打开独立答题窗口。
- 答题走现有 Python 执行器，不新增心跳发送器，不干扰 ZHS 原有视频心跳与并发上限。
