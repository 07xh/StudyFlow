# StudyFlow 0.1.1-rc.56｜AI 掌握度只读查看与分课程恢复

## 修复
- 在 AI 掌握度的知识点列表中，点击知识点只检查是否有已打开的本地练习草稿，不再自动调用建卷接口。
- 没有草稿时显示所选知识点及明确的「开始练习」按钮，只有点击该按钮才向知到创建新练习卷。
- 已有手动草稿仍会恢复，无须重复建卷。快速切换知识点时，过时的异步回包不再覆盖当前选择。
- 掌握度自动调度新增按课程隔离的状态快照；进入课程 B 后不会覆盖课程 A 的待核验交卷记录。
- 兼容 rc.55 单个 status.json 的历史状态；存在旧记录时仍可按同一课程恢复，避免丢失正在核验的试卷。
- 扩展 Python 回归测试：切换课程保留提交标记、从旧格式恢复、禁止非法文件名，以及从另一门课程返回后恢复原课程。
- 更新 React 交互测试：知识点选择和服务端建卷必须是两个独立动作。

## 不变
- 保留 rc.55 的会话复用、登录错误分类、只读交卷核验以及四种首轮策略。
- 不修改 ZHS 官方视频播放心跳、不重复发送交卷请求。
- 自动测试只能证明协议使用与本地状态一致，真实知到账号仍须安装后验收。

版本：`0.1.1-rc.56`。
