# 学序 StudyFlow 0.1.1-rc.29｜最新开发整合版

## 本版包含

- **继承 rc.28 的全局设置中心**：LightC 风格的完整二级悬浮窗口、分栏导航、遮罩关闭、键盘交互、深浅主题及窄窗口适配均保留。
- **学习通代码整合（实验性、尚待真实账号验收）**：学习通进入统一导航和课程工作台，包含账号会话管理、真实课程与文件夹读取接口、章节与任务元数据浏览、搜索和筛选及本地参数配置。
- **学习通运行与状态模块的开发代码**：相关模块与 Sidecar / Tauri IPC 已作为开发功能整合。自动化测试通过不等于学习平台真实服务端验证；界面中本地状态与服务器确认状态的含义不应混用。请勿将未核验的本地任务记录视为课程已完成。
- **应用兼容**：知到、雨课堂原有运行器、课程进度、服务器核验、平台参数弹窗、搜索和筛选保留；没有用空目录或模拟课程伪造平台结果。
- **工程化**：解决学习通开发分支与 rc.28 主分支在设置入口、平台导航、状态测试和 Python 依赖上的冲突；同步相关依赖、源代码和回归测试。

## 重要：学习通验收范围

**本版为 RC 预发布，学习通功能仍属于实验性集成，不应视为已完成真实业务验收。**

当前仅确认 Python / React / 浏览器与 Windows NSIS 自动化检查；尚未完成本人授权学习通账号的真实 Windows 登录、完整课程文件夹同步、章节和任务状态准确性、会话恢复及任务执行的端到端验收。在取得真实现场验收前，不保证对应功能可用或准确。

这些项目需要在本机用本人账号验证，并且不应将 Cookie、密码或原始抓包文件提交到 GitHub 或聊天记录。若平台未提供可验证的完成状态，应显示未核验或待核验，不得自行换算成官方课程已完成。

## 安装与更新

- 正式主分支构建的 Windows x64 NSIS 安装程序经安装、升级启动和卸载检查通过后才创建本候选版本。
- 保留旧版 rc.28 安装包；新版本通过 GitHub Release 分发，由学序更新器下载、校验 SHA-256，退出应用后手动安装。
- 新版安装与自动化验收不能替代本人账号的实时业务验收。
