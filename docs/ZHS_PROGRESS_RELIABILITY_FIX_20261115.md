# ZHS 本地进度与服务端核验可靠性修复（2026-11-15）

## 修复范围
- 复用原版 ZHS 0.1.5，**不修改心跳生成、网络发送内容、倍速、节奏、风控或请求重试算法**。
- 同一平台的任务状态轮询改为单飞（single-flight），避免请求慢于两秒间隔时积压。
- 状态读取失败展示明确提示，不把传输故障错误地当作“未启动”。
- 任务正常结束或停止后继续使用已有 `zhidao.progress.verify` 服务端只读核验，不依赖本地模拟数值或进程退出码判定课程完成。
- 一次核验未成功时提供本课程手动重试按钮，重试不启动任务也不重发进度。
- Rust 读取本地模拟进度快照时拒绝符号链接，防止通过路径间接读取其他本地文件。

## 自动化覆盖
- React 任务组件回归：核验请求失败后能只读重试；核验结果仍绑定当前课程。
- Node 静态契约：同平台请求单飞、错误展示、重试入口。
- Python 静态契约：Rust 快照使用 `symlink_metadata`。
- 原源码 SHA 锁定与既有 Windows Tauri、NSIS 门禁继续生效。

## 尚需人工验收
1. Windows 真实安装包中知到登录、共享课与 AI 课程读取；
2. 网络中断/恢复以及正在运行时用户手动停止；
3. 核验失败后从“重新核验服务器进度”恢复，并检查服务器时间戳；
4. 原版 ZHS 0.1.5 源码与运行行为不变。
