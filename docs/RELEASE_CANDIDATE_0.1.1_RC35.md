# 学序 StudyFlow 0.1.1-rc.35｜知到进度与课程切换可靠性修复

## 本版修复

- **共享课长时间播放进度采样**：当 ZHS 原版控制台持续输出相同的有效视频百分比时，延续本地只读采样时间戳，避免在仍有真实输出时误判超过 18 秒。
- **章节切换与并行展示**：没有采样的新资源使用中性空进度轨道，旧章节的百分比不会错误附着在下一章节；同章节顺序、不同章节并发的原有调度保持不变。
- **跨课程工作区隔离**：知到官方播放器、ZHS 原版面板、章节列表和服务器核验面板按课程键重新绑定，拒绝上个课程迟到的异步响应。
- **章节只读刷新**：缓存没有可用章节证据时尝试对当前课程做一次单课服务器核验；手动“刷新章节”读取最新服务器记录，并与本地缓存来源分开展示。
- **官方 WebView2 播放观测**：为学序隔离的运行时副本应用版本守卫，把本地实际 HTML5 播放状态观测收敛到 6 秒间隔，兼容 Rust 18 秒过期窗口；原版 `legacy/zhidao/Official-MediaController.js` 仍保持逐字节原样和哈希校验。
- **自动化回归**：增加 Python、React/Node、Rust 对重复采样、课程切换、资源交接、原版文件完整性与官方播放器本地观测期限的检查。

## 向前兼容

- 完整保留 rc.34 中的 U校园接入、学习通任务队列、雨课堂、知到上游 ZHS 原版执行逻辑以及 Windows 进程树管理和停止→重启修复。
- 本次修复只涉及本地进度观测、UI 归属、缓存与服务器只读核验；不改变知到/智慧树上游的视频心跳、学习记录上报、倍速执行算法及鉴权协议。

## 验收边界

- 自动化测试和 Windows NSIS 构建/安装/升级/卸载通过之后才能发布本候选版本；仍需使用本人真实账号、多个章节连续播放，在 Windows 上进行长期现场验收。
- 本地播放片段百分比、进程状态和服务器学习进度是不同证据。采样失败时不编造数值，任务本地结束不代表服务端已确认课程完成。

## 安装与升级

候选版本：`0.1.1-rc.35`。由主分支对应 SHA 的独立 Windows 发布工作流生成，旧版 rc.34 安装包不覆盖。升级前请停止正在运行的学习任务。
