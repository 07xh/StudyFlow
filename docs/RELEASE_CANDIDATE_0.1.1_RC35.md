# 学序 StudyFlow 0.1.1-rc.35｜下载续传与可选镜像支持

## 本版更新
- **无需 R2**：更新仍使用 GitHub Releases；不用创建 Cloudflare R2 桶，不需要额外付费云服务或账号。
- **HTTP 断点续传**：安装包按 SHA-256 关联临时片段，网络中断后可恢复；服务器忽略 Range 时自动重新开始。
- **完整性校验**：沿用 GitHub Releases SHA-256，未校验安装包不会标记为已下载，也不执行自动安装。
- **下载源接口**：保留由维护者在打包前配置的可选公开 HTTPS 镜像，默认关闭；未配置时 UI 明确标识，不调用未知第三方 GitHub 代理。
- **现有功能保持**：保留 rc.34 的知到、雨课堂、学习通、U校园与原有更新通知和手动安装流程。

## 验收及限制
- GitHub API 仍是更新版本信息唯一权威来源；没有公开镜像时下载仅依靠 GitHub，并不声称具备第三方镜像加速。
- 需要 Windows NSIS、前端和 Python CI 全部通过，再合并发布；实际安装包下载/恢复还应在真实 Windows 网络进行验收。
- 当前无实时下载百分比或静默自动安装。

版本：`0.1.1-rc.35`。仅在合并主分支、构建和发布流程完成后视为正式 Release。
