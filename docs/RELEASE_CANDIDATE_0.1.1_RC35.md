# 学序 StudyFlow 0.1.1-rc.35｜安装包下载源与断点续传

## 本版更新

- **下载源管理**：在「设置 → 版本与更新」支持自动、GitHub 官方源与可选 Cloudflare R2 镜像；可以启用或关闭失败切换。旧版 A/B 更新偏好自动迁移。
- **可信校验**：仅使用 GitHub Releases 返回的版本和 SHA-256；R2 只提供同一安装包的字节镜像，下载不执行安装器，也不向镜像泄露账户或学习平台会话。
- **断点续传**：安装包临时片段与版本校验值关联；支持 HTTP Range，服务器忽略 Range 时安全重新下载，校验失败不保存成完整安装包。
- **发布管线**：已发布且完成校验的 Windows NSIS 安装包可自动同步至 Cloudflare R2；需要管理员先配置存储桶、公开 HTTPS 域名和 GitHub 仓库变量/密钥，未配置时仅保留 GitHub 官方源。
- 保留 rc.34 的四平台入口、知到运行器/进程清理、学习通任务和 U校园只读接入，不修改原有学习业务协议。

## 已知限制

- 新版本发现依赖 GitHub API；R2 镜像在 GitHub 元数据无法读取时尚不能独立更新。
- 镜像未实际配置并通过真实 Windows 网络下载验证之前，不应称为已经上线可用。
- UI 目前显示下载进行中和最终来源，不展示精确实时下载字节百分比；安装仍需用户在关闭学序后手动执行。
- RC 测试安装包与已经正式发布的 Release 安装包是不同的渠道。

## 安装与升级

版本：`0.1.1-rc.35`。此版本仅在主分支合并、Windows NSIS 测试和发布工作流通过后生成；升级前先停止运行任务。
