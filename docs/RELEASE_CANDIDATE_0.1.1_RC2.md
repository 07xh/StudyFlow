# 学序 StudyFlow 0.1.1-rc.2 · 雨课堂逐视频进度

此版本是经过 CI 校验的 Windows 候选版，不代表完成真实账号端到端验收。

## 新增
- 雨课堂原版批量任务的三个并发槽位可显示当前视频名称、任务编号和执行状态。
- 独立展示当前视频的本地事件进度、位置、总时长；服务器响应进度单独显示，并区分开始前、定期和最终查询。
- 新增可折叠、内部滚动的逐视频明细（单次日志最多记录前 256 个已出现的任务）。
- 通过现有原版 Worker 的真实 Python 调用栈标注只含数字的进度行，避免并发日志互相串百分比。
- 无法归属的旧日志仍显示视频名称与状态，但不会猜测进度。支持保留已结束视频的实际服务器响应。

## 保留
- `legacy/yuketang/main.py` 原字节不变，心跳协议、上报算法、学习速率、账号及任务启动入口不改。
- 学序知到平台、ZHS 可靠性补丁及已有其他功能不变。
- 不将客户端本地模拟位置、心跳发送成功或流程退出状态冒充服务器学习完成。

## 验收
Python/React/浏览器 UI 测试、Windows NSIS 打包及清洁安装/升级/卸载需全部通过；真实账号并发运行和服务端返回值的端到端验证仍需在 Windows 上执行。
