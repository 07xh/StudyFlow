# 学序学习通｜本人账号只读验收门禁

本清单只适用于本人授权的学习通账号。**不需要把 Cookie、密码、课程 URL、学生标识或原始抓包文件上传到聊天或 CI**。不以本机测试通过代替真实平台读取成功。

## 门禁 A：Windows 安装包（自动化）

- 核对目标 PR HEAD 的 GitHub Actions，而不是历史提交。
- Python 回归、React/IPC、Windows NSIS 三项均为 success。
- Windows job 的 `scripts/test-windows-install.ps1` 已验证安装、升级、启动、退出、卸载及本机数据保留。
- Windows 打包产物须与**本次 HEAD**的 Actions run 对应；未通过前不得合并或发布。

## 门禁 B：本人账号（Windows 真机，只读）

1. 安装上一步同一 commit 的构建产物。核对启动后显示的应用版本，确认 Sidecar 一起安装。不要用旧版 EXE 代替本轮构建。
2. 在本机学序中连接自己的学习通账号。凭据只保留在本机 Windows 凭据管理器；不将原始凭据放入测试记录。
3. 打开「学习通 → 课程」，执行一次真实同步，并与学习通官方课程页面核对课程名称、课程数和文件夹内课程；**缺失课程或接口报错时不能视为通过**。
4. 进入一门真实课程，核对章节标题、数量、完成/未解锁标记。在任一可读取章节中展开任务点，核对任务类型、名称和完成标记；未知状态应显示「待核验」，而不是完成或 0%。
5. 切换至另一门课程，确认上门课程的章节和任务点不会串入；使用搜索、筛选、收起/重开和手动刷新检查 UI。
6. 正常退出并重启学序，再读取课程与章节；如本机有**事先存在**的任务状态文件，检查历史状态仍可查看，并显示「历史记录（未运行）」而非冒充仍在运行。没有历史文件时标记此项未覆盖，不必为测试制造学习进度记录。
7. 核对课程总进度：如果平台接口未提供可验证的总进度，界面必须使用「未核验/未知」，不能把本机记录自动折算成课程完成度。

## 通过标准与记录

记录本次 PR commit SHA、Actions run URL、Windows 实际应用版本，以及每项的 PASS / FAIL / NOT TESTED。可以提供**遮盖姓名、学号、账号、课程标识和敏感信息后的截图**，用于进一步定位界面问题。不可用模拟课程截图冒充真人验收。

本清单**不启动任何学习任务、不生成学习进度请求，也不改变平台完成状态**。真实账号验收由本机操作者执行并确认，未提供现场证据前状态保持「待验收」。
