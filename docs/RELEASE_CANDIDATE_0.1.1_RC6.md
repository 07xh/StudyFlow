# 学序 StudyFlow 0.1.1-rc.6 · ZHS 退出码 1 的隐私安全诊断

## 问题
Windows rc.4 实机出现原版 ZHS 进程启动后短时间退出，显示退出码 1，但未获得本地视频观察值。服务器进度能读取，并不能证明任务成功完成。

## 本候选版改动
- 不改变原版 ZHS 发送器、运行速度或学习进度算法。
- Python 原版进程在异常退出时仅写入单次任务的固定分类码，禁止写入 Cookie、会话、URL、请求数据或原始 traceback。
- Rust 监督进程按一次性 token 读取、验证并清理小型诊断记录；无有效诊断时继续明确显示未知。
- ZHS 错误类别及退出码移动到课程任务的「任务运行状态」下方，解决报错藏在页面底部的问题。
- 新增 Python、Rust、UI 自动化测试，涵盖非零退出、错误分类、无效 token 和敏感信息不显示。

## 验收
- 完整 Python + React/UI + Rust/Windows NSIS 构建与安装/升级/启动/卸载测试均通过后，才可将此版本作为正式 rc.6 预发布。
- 真实 Windows 知到账号上的视频任务执行仍需实机复现；如果继续退出，请查看新显示的错误类别。rc.6 仅改善诊断可见性，不表示原版任务已经通过真实账号端到端验收。
