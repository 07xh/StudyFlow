# 学序 StudyFlow 0.1.1-rc.46｜ZHS 自选必学 / 选学任务

## 新增功能
- ZHS 智慧课程「课程范围」增加三种明确模式：**仅必学**、**仅选学**、**必学＋选学**。与现有「全部资源 / 视频 / 文章 PPT」及选定章节 / 知识点组合使用。
- 资源目录在进入执行队列前按服务端提供的 `resourcesSyncType` 分类筛选，并在原版资源遍历层再次检查，不会将本次未选择的另一类资源顺带执行。分类缺失时，单独选择必学或选学不会猜测并插入任务。
- 模式随课程保存到现有的课程范围本机存储，和其他设置一致需要点击「保存参数」才生效；关闭未保存弹窗可放弃更改。旧版只支持 `learn_optional` 开关的配置自动沿用原来行为：未勾选对应「仅必学」，已勾选对应「必学＋选学」。
- 原 ZHS `--learn-optional` 参数保持与本次选择一致，`requirement_mode` 仅控制 StudyFlow 本地任务筛选，前后端均拒绝不一致或伪造的选项。
- 普通共享课不具备智慧课程必学/选学分类，仍使用共享课既有的可执行视频列表。原版 ZHS 0.1.5 心跳协议、请求报文和发送节奏保持不变。
- 新增互斥筛选、旧设置迁移、原版遍历一致性、设置保存和重新打开的回归测试。

## 与 rc.45 的关系
- 保留上版的逐任务服务器只读回读、未确认状态提示、AI 阈值冲突识别、失败退出码传递和 Windows 安装验收机制。
- 自选必学 / 选学仅决定执行范围；服务器观看时长增长、资源完成状态和课程整体进度仍由平台只读查询独立确认，选学不自动算作必学课程进度。

## 验收
- Python、React/IPC、Windows NSIS 构建与安装升级测试完成后才可合并发布。真实账号服务器写入和选学权限规则仍需实际环境核验。
- 不删除登录态，不更改其他学习平台逻辑。
