# 学序 StudyFlow 0.1.1-rc.52｜修复知到全自动掌握度启动入口

## 入口可见性修复
- 知到课程工作台顶部操作栏新增醒目的「全自动掌握度」按钮。点击直接打开完整的后台任务启动面板，无需滚动到页面下方或先展开默认收起的区域。
- 原「AI 掌握度」手动练习折叠区保留，并新增「配置并启动全自动」快捷按钮。
- 自动启动面板通过单一二级弹窗展示；不会重复挂载两套自动任务控制面板，也不会另开浏览器。
- 对共享课或尚未识别为 AI 课程的条目，入口仍然可见，点击后说明不能执行的原因以及同步课程的建议，不会悄悄隐藏启动入口。
- 关闭启动弹窗只关闭界面，不会终止已启动的后端任务；重新打开可查看任务状态并操作暂停、继续或停止。

## 保留 rc.51 功能
- 自动扫描本门 AI 课程的所有章节知识点，按配置自动创建练习卷、作答、保存、提交并回读官方掌握度。
- 首轮四种策略：已验证题库与有限试答、题库优先再 AI、首轮 AI 优先、首轮随意作答并提交。
- 目标分数、轮次上限、停滞停止条件、运行时间和 AI 请求次数可配置；保留手动习题页面、原 ZHS 视频心跳与播放器。

## 验证和限制
- React/TypeScript 构建、UI/IPC 入口回归、Python 自动调度测试和 Windows NSIS 安装/升级/启动验证通过后才正式发布。
- 真实知到账号完成率和答案公开范围仍需线上验证。CI 通过不等于平台保证全部知识点达到 100 分。

版本：`0.1.1-rc.52`。
