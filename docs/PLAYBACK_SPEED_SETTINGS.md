- 知到 ZHS 原版运行器：继续遵守 1–2× 目标与上限，只将输入步进提升到 0.01×，不更改上游心跳发送逻辑。
- 雨课堂：现有 0.1–4× 输入精度从 0.1× 改成 0.01×，不扩张后端范围。
- 保留 Git 快照中的 `legacy/zhidao/Official-Player.ps1` 原文件。Rust 只在隔离运行目录的本地副本中将固定倍速白名单改成范围校验，且采用严格版本匹配，避免覆盖未知上游版本。

## 键盘直接输入
- 知到官方播放器的自定义倍速改用文本编辑框，支持直接输入 `1.75`、`2.35`、`3.5` 等小数；聚焦时选中已有值，键盘输入过程中不会强制转换成数字。
- 按 `Enter` 保存，Tab 离开会将合法的 `1.`、`.75`、`3.50` 规范化；空值、超限、超过两位小数均不能保存。
- 使用 `inputMode="decimal"` 兼容带数字小键盘的设备。仅在失焦/按 Enter 后对无效输入提示错误。
- 保留常用倍速下拉框、撤销修改和独立的平台限制。后端沿用严格校验，不会提交原始不完整文本。
