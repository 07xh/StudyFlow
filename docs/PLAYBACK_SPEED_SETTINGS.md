# 学序：播放倍速设置（当前实现）

| 平台 / 运行方式 | 可输入范围 | 精度 | 保存行为 |
| --- | --- | --- | --- |
| 知到官方 WebView2 播放器 | 0.5–4× | 0.01× | 本机保存，下次启动读取 |
| 知到 ZHS 原版任务 | 1–2× | 0.01× | 按课程设置，不更改 ZHS 上游协议 |
| 雨课堂 | 0.1–4× | 0.01× | 保留平台配置与原有执行规则 |
| 学习通 | 保留现有平台边界 | 不在本次改动中 | 保留现有执行逻辑 |

## 知到官方播放器交互

- 在设置中直接键盘输入（例如 `1.75`、`2.35`），或选择常用档位。
- 输入时保留原始字符串，不强制截断中间的小数点；按 Enter 保存，失焦规范化合法值。
- 无效、超限或超过两位小数的输入无法保存，并在失焦或尝试保存时提示。
- 播放器每次启动前重新读取已保存参数，避免使用组件缓存的旧设置。
- 目标倍速不等于实际倍速：官方播放器通过只读 HTML5 视频采样显示实际 `playbackRate`。
- 本机视频播放位置与倍速均不代表服务器确认的观看进度。

## 源码与数据边界

- `legacy/zhidao/Official-Player.ps1` 和 `Official-MediaController.js` 为快照保护的原始资源，保持逐字节不变。
- Rust 仅对学序私有运行目录中的副本执行严格定位的倍速校验和观测增强；任何旧版锚点缺失或重复时拒绝修补。
- ZHS 原版 1–2× 约束保持不变；雨课堂保持原有 0.1–4× 后端范围；不改动平台心跳实现。
- 保存前由前端规范化数值，Python 持久化服务和 Rust 启动接口各自再次校验。

## 第二批清理
- 移除播放器界面重复的默认设置对象与 `settingsLoaded` 启动门禁；按钮启动时仍从本机持久化设置重新读取最新值。
- 初次读取的参数仅作最近读取值展示，不再决定能否启动。初次读取失败也能通过启动时的读取操作重试，且不会用旧默认值代替有效的保存设置。
- 设置面板显式比较五个持久化字段判定是否有修改，减少 `JSON.stringify` 对字段顺序的依赖；没有修改时不再重复保存。
- 修改参数时清理上次操作的状态提示，避免旧“保存成功”与未保存草稿同时出现。
- 删除设置网格重复的 CSS 布局声明，保留响应式断点。

## 第三批清理
- 审查前端组件引用后保留仍被工作台调用的旧兼容组件和监控服务，不以文件名“Legacy”为删除依据。
- 知到运行日志使用统一的 `ActivityEntry` 类型，避免局部重复声明。
- 官方播放器关闭后核验使用 `PlayerStatus` 的字段子集，避免与状态面板重复维护相同字段及其类型。
- 将两段回调 ref 同步 effect 合并为一段；错误提示交给 `friendlyBridgeError` 的安全映射，禁止在活动记录中直接展示未知异常文本。
