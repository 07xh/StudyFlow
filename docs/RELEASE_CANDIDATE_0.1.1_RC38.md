# 学序 StudyFlow 0.1.1-rc.38｜U校园会话过期识别与隐私登录优化

## 本次更新
- U校园官方内嵌 WebView2 登录窗口加入私密模式。在受支持的 Windows WebView2 运行时中，关闭登录窗口不会保留可复用的网页登录配置；保留旧版环境的兼容处理并继续提供手动 Cookie 导入。
- 从官方登录窗口导入 JWT 之前，在本机检查其 `exp` 是否已过期。过期时拒绝导入，保留原有 Windows 凭据，并显示单独的过期提示；不向 UI 返回 Cookie/JWT。
- U校园账号设置展示本机 JWT **自报的**“已过期 / 即将过期”提示。该状态来自未验证签名的令牌声明，仅用于提前提醒；**不等于服务器已验证账号**。
- 对本地已知过期的 JWT，课程列表及单元/任务进度的只读 GET 在发起之前就返回 `UCAMPUS_SESSION_EXPIRED`，不继续使用该过期令牌。
- 从 U校园执行“退出并清除”时，同时请求关闭并清理应用内官方登录窗口；失败时明确提示用户处理。高级 Cookie 输入表单默认收起，减少设置页面拥挤。
- 增加 Python、React 与 Rust 的过期边界、无令牌泄漏及 UI 回归测试。

## 保留功能
- 完整保留 rc.37 官方页面扫码/验证码流程与本机会话导入。
- 不删除账号密码登录、手动 Cookie 导入、课程、章节、服务器只读核验及既有其他学习平台功能。
- 继续继承 rc.36 公共 GitHub 代理、校验与断点续传的更新能力。

## 验收说明
- CI 通过说明 Windows 打包、安装升级与本地契约测试通过，不证明任一真实 U校园账号已经能完成扫码/获取 JWT/读取课程。
- JWT `exp` 只用作本地有效期提示，服务器仍可能提前撤销会话。缺失或不可解码的 `exp` 标为 `unknown`，不伪称有效。
- WebView2 的私密模式依赖运行时支持；关闭窗口清除本机浏览数据不等同于注销官方服务器会话。
- 仍需本人在 Windows 电脑上实际完成官方扫码/验证码、Cookie 导入、课程读取、重新启动与退出清理验收，不能以空列表或 HTTP 成功冒充完成接入。
- 只有主分支的 Windows CI 和 GitHub Release 实际成功，才能称为已发布版本。

版本：`0.1.1-rc.38`。
