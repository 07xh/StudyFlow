# 学序 StudyFlow 0.1.1-rc.31｜学习通实时章节队列与进度展示

## 本轮更新

- **学习通实时章节队列**：展示正在运行、排队和暂停的章节数，来自本机任务队列实际快照；不会将“已配置并发数”误当作实际运行章节数。
- **逐任务进度**：章节与资源名称更清晰，本地计时显示为时间条（分:秒），待处理、排队、运行等状态分别标注。
- **服务器状态隔离**：本地计时、请求发送记录与学习通返回的确认状态分别展示；无服务器确认不得标注为课程已完成。
- **首次运行默认设置**：本地心跳面板的“首包申报整段完成”选项默认关闭。此更新未改动原心跳包生成、发送和限流算法。
- **课程卡片可读性**：保留主分支 PR #152 对课程进度文字的字号和排版优化。
- **延续 rc.30 的修复**：知到 ZHS 原版启动/停止控制、当前内容区域和服务器进度核验分支归属修复，以及 LightC 风格全局设置弹窗均继续保留。

## 适用范围和验证限制

学习通功能仍为实验性集成。Python、React 和 Windows NSIS 自动化测试不等于真实学习通账号的登录、章节数据、任务执行或服务器学习记录已经通过端到端验收；应用不应据此将任务标记为官方完成。U校园5.0 接入 PR #151 仍为草稿，尚需本人账户和脱敏接口样本核验，未纳入此安装版。

## Windows 安装与更新

本候选版为 Windows x64 NSIS 安装包，版本 `0.1.1-rc.31`。应用内「设置 → 版本与更新」选择 Beta 通道检查更新，下载、核对 SHA-256、退出学序后手动安装。

新版只会在与最新 main 提交一致的正式构建完成前端和 Windows 安装、升级、卸载验收后发布。不会覆盖既有 `rc.30` 安装包。
