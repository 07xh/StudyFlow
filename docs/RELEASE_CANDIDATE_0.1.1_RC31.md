# 学序 StudyFlow 0.1.1-rc.31｜学习通队列与任务进度整合版

## 本版更新

- **学习通章节任务队列**：新增从本机运行状态读取的真实队列摘要，包括当前运行、已排队及暂停中的章节数量；不使用配置的并发上限冒充实际运行数。
- **逐任务进度显示**：课程工作台显示每项任务本地计时进度条、章节和运行状态，将本地计时与学习通平台返回的确认记录放在不同区域。
- **默认执行参数**：将界面和运行器的「首包申报整段完成」默认选项改为关闭；此次更新不改动原有网络发送、包生成和限流算法。
- **UI 与 IPC 对齐**：同步学习通进度状态 TypeScript 类型、Python 队列只读快照、统一前端组件及集成目录镜像，补充对应回归测试。
- **继承修复**：包含 rc.30 的学习通课程工作台适配、此前知到 ZHS 原版运行区及服务器核验入口恢复、全局设置悬浮窗口、旧版知到/雨课堂的已有功能。
- **课程卡片可读性**：继承主分支中最新的进度字号和显示优化。

## 真实数据与验收边界

此版本仍属于候选/实验性发布。学习通课程目录、真实账号的 Windows 登录、章节执行结果、服务端学习进度和断点恢复均需本人授权环境下进行端到端验收。当前自动化测试中的离线示例与真实平台业务结果不同；本地计时、提交记录或成功请求不代表平台官方已认定课程完成。

本版本保留知到、雨课堂既有执行逻辑，未改变用户课程搜索与筛选习惯。U校园 5.0 只读接入 PR #151 尚为 Draft、缺少真实接口样本，**未纳入此安装版**。
