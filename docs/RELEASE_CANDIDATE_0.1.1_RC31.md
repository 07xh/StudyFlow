# 学序 StudyFlow 0.1.1-rc.31｜学习通章节队列与真实状态展示

## 本版更新

- **学习通章节队列**：从当前任务快照和队列获取运行、排队、暂停与尚未开始的章节数据，不再把配置的并发数误当成实际运行章节数。
- **逐任务进度**：增加章节/任务的可读进度条，显示本地任务计时，并将平台确认结果单独呈现。不能用本地计时推断学习平台已经完成。
- **默认参数修正**：界面的「首包申报整段完成」默认改为关闭；相关运行器默认值同步对齐。本次进度视图更新不改动原有心跳包构造、网络发送或限流算法。
- **状态和测试**：补充队列在任务尚未启动、正在运行、结束以及跨课程情况下的回归测试，并完善 React 状态显示测试与 TypeScript IPC 类型。
- **沿用已合并修复**：保留 rc.30 的知到 ZHS 原版运行区、知到服务器进度核验入口、LightC 风格全局设置浮层、雨课堂页面和学习通响应式布局；不回退现有搜索、筛选和运行控制。

## 实验功能与真实数据边界

学习通自定义模块目前已经接入本地长期运行的 Python Sidecar、Tauri IPC 和统一课程工作台；本版改善的是队列与进度的**显示、归属和本地状态可靠性**。目前尚未完成本人真实账号在 Windows 上的登录、课程章节读取、会话恢复和服务器任务核验的完整端到端验收。本版不承诺学习通真实业务可用，不把本地计时、请求发送次数或未确认状态标为平台已完成。

U校园实验性只读接入仍在独立 PR #151，缺少真实 API 样本，**未纳入本版**。

## 发行与安装

- 本版是 **0.1.1-rc.31**，Windows x64 NSIS 预发布；保留 rc.30 已发行包，不覆盖原有 tag 或二进制。
- 以合并后的 **main 最新提交**为构建基准，CI 的前端测试、Windows 构建、干净安装、升级启动和卸载全部通过后才发布 Release。
- 使用学序「设置 → 版本与更新」Beta 通道检查更新；下载安装包经现有 SHA-256 校验后退出应用，再手动安装。
