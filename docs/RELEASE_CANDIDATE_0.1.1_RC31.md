# 学序 StudyFlow 0.1.1-rc.31｜章节队列与进度展示更新

## 本版主要更新

- **学习通章节队列**：课程工作台可展示当前章节的排队、执行、暂停与结束状态；章节数量从运行队列的真实快照读取，不再把预设并发数误认成正在执行的章节数（PR #153）。
- **逐任务进度**：各条任务提供本地进度条与已处理时长，平台服务端返回的确认状态保留为独立信息列，避免混淆本地状态与真实学习完成情况。
- **任务状态更清楚**：区分尚未开始、排队中、进行中和终止等状态，并对运行中的项目提供可读的进度详情。
- **课程卡片进度可读性**：增大进度数值并改善排版，减少课程列表查看数字的困难（PR #152）。
- **平台图标**：恢复首页学习通平台卡片的可见图标（主分支此前的修复）。
- **保留先前修复**：包含 rc.30 的知到 ZHS 原版运行控制恢复、服务器进度核验归位、全局设置二级悬浮窗口，以及知到和雨课堂现有业务功能。

## 验收范围及限制

- 本候选版的 UI/IPC/Windows 安装检查由 GitHub Actions 执行；发布需验证本次主分支的完整安装、升级和卸载测试。
- 学习通部分继续作为实验性集成：本次改动着重于运行队列的可观察性和界面反馈，**不代表**已完成本人账号的登录、课程任务、服务端学习进度及完成状态的真实端到端验收。
- 本地进度条、调度状态和日志记录不是平台认证的观看时长或课程完成凭据。平台状态未知时继续明确标记为未确认。
- U校园第四平台仍为独立 Draft PR #151，真实协议样本尚待获取，未纳入本次安装包。

## 更新方式

- 版本：`0.1.1-rc.31`，Windows x64 NSIS 安装版，作为独立预发布，不覆盖旧版安装程序。
- 通过应用中「设置 → 版本与更新」的 Beta 通道检测新版本，下载并校验 SHA-256；安装前关闭学序。
