# 学序 StudyFlow 0.1.1-rc.31｜章节实时队列与学习进度可读性优化

## 本版更新

- **学习通章节任务实时队列（PR #153）**：在同一学习通课程工作台展示服务端适配器返回的章节等待、运行、暂停状态与章节数量；不再用配置的并发上限冒充实际运行数量。
- **学习通逐任务进度**：独立展示当前任务的本地进度条和任务生命周期状态；与平台确认进度分列，避免把本机执行记录误认为平台完成。
- **学习通课程状态隔离（PR #148）**：课程切换时隔离异步返回和日志，防止迟到的旧课程请求覆盖新课程信息。
- **学习通布局与首页标识修复（PR #149及后续提交）**：修复课程运行面板挤压、空任务状态、首页平台图标缺失，并改进窄窗口。
- **课程卡片进度数值可读性（PR #152）**：放大课程卡片上的进度数字，提高对比与可读性。
- **知到 ZHS 原版控制区修复（PR #147）**：在知到课程页恢复原版模式的运行控制和服务器进度核验区域；保留现有任务执行器。
- **原有 LightC 风格全局设置浮层**：完整保留主工作台上方的二级悬浮设置中心、更新中心及原有平台设置弹窗。

## 验收边界

- 学习通自定义心跳相关代码属于**实验性集成**。此版说明仅包含任务控制界面、状态与日志展示的接线和自动化验收，不声称本人账号真实课程读取、服务端进度变化、任务执行或恢复已经验收。
- 本地时间位置、请求发送次数与平台正式课程完成状态是不同概念。缺乏平台可确认的进度时，应显示“待核验”，不以本机推测替代。
- U校园第四平台仍在独立 Draft PR #151 中，缺少脱敏真实接口样本，**未包含于本候选版本**。
- 知到和雨课堂既有平台账号、播放控制、课程运行、搜索筛选和进度核验接口不因本版 UI 优化而改变。
- Python、React/Node、Chromium 浏览器与 Windows NSIS 构建/安装/升级/卸载检查仅证明自动化工程门禁，不替代本人 Windows 环境现场核验。

## 安装与更新

版本：`0.1.1-rc.31`。生成新的 Windows x64 NSIS 安装包，不覆盖已发布的 `rc.30`。只有在当前主分支 HEAD 对应的 React、Windows 构建和安装测试全部成功后，GitHub Actions 才会创建一次性 GitHub Release。

请在学序「设置 → 版本与更新」选择 Beta 通道检查更新，下载时校验 SHA-256，关闭运行中的学序后安装。
