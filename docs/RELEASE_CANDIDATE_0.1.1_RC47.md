# 学序 StudyFlow 0.1.1-rc.47｜ZHS 无资源知识点队列接入

## ZHS 更新
- 智慧课程无资源知识点：当 ZHS 原版资源列表为空、智慧树官方目录明确资源总数为 0 且知识点未完成时，自动纳入现有章节任务队列，无须另开官网页面，也不新增第二套调度器。
- 使用已有 ZHS 授权会话，对匹配的知识点自动发送一次智慧树页面进入学习记录，然后重新读取服务器学习进度。
- **仅以服务器进度回读判定完成**：服务器未增加则显示“未确认”，不伪造成功状态，也不重复发送任务或构造观看时长。
- 桌面与移动目录进度不一致、资源数缺失、资源列表异常的知识点保持只读提示，不进行错误的资源心跳。
- 原版 ZHS 视频/PPT/文章心跳、倍速、必学/选学和其他平台不变。

## 其他
- 设置 → 关于与开源：新增「开发者网站」入口。仅显示该名称，不在入口标题附加域名；外部链接由系统默认浏览器打开。

## 重要说明
- 2026-11-21 提供的 HAR 中没有捕获无资源知识点由 0% 变成 100% 的实际过程。代码已接入 ZHS 队列，**但“进入记录必然使知识点完成”仍未经真实账号验证**。本版本为候选测试版；不会把日志请求成功等同于服务器学习完成。
- 构建、Python、React/UI、Windows 安装验收均应由本版本 GitHub Actions 检查后才发布，不会改动已有 rc.46 二进制。

版本：`0.1.1-rc.47`。
