# 学序 StudyFlow 0.1.1-rc.19｜云端新版本提醒与更新内容修复

## 更新提醒
- 应用启动后检查 GitHub 已发布的正式 Release；运行过程中每 20 分钟检查，Windows 窗口重新获得焦点时也检查。
- 只有发现**高于当前已安装版本**的新 Release，才显示「发现新版本」弹窗；直接显示官方 Release 更新说明，不再额外请求一次日志。
- 弹窗显示当前版本和新版本，提供「查看更新」「暂不更新」；关闭后同一版本不反复弹出，下一版本发布后重新提醒。

## 安装后首次启动
- 已安装新版本后，继续显示「学序已更新」，展示相应版本实际更新内容。
- GitHub 接口超时或更新记录为空时，针对本次安装的版本回退至安装包内置的候选版说明；明确标注离线来源，避免把未证实内容当成在线发布记录。
- 历史更新日志提供重试入口，保留 GitHub 官方发布页外链。

## 版本选择与回归
- 修复 GitHub Releases API 返回顺序并非语义版本顺序时，可能先选到较旧 RC 的问题；优先选择真正较新的已发布版本。
- 历史日志按实际版本号降序排列，新增更新提醒去重、离线候选版说明及 Release 非顺序返回的测试。

## 雨课堂服务器完成状态修复（PR #108）
- 修复视频观看率仍显示 98.1%，但雨课堂服务器明确标记已完成时，学序错误归类到「待完成」的问题。
- 分开显示服务器完成标志与原始观看进度，不把 98.1% 直接篡改为 100%。
- 章节进度新增「只复核此节」，任务结束后支持有限次数单节服务器复核，避免为了一个视频重复核验全部章节。
- 仅在服务端返回可信完成证据时计入「已完成」，保留原视频播放与服务器上报机制。
- 新增完成标志/观看率冲突、重复视频名称、单节复核等回归测试。正式完成状态仍需在用户 Windows 雨课堂账号中核对。

## 雨课堂保存会话前置校验（PR #110）
- 修复未填写课堂 ID、学校 ID 时，点击保存会话却只得到模糊错误、且难以找到必填字段的问题。
- 账号与连接页面直接指出缺少的字段或 ID 格式错误（1–24 位数字）；未补齐前不会调用保存接口。
- 提供「前往填写课堂 ID、学校 ID」，切换到高级管理并自动展开「课堂范围与章节内容」，即使该区域曾被折叠。
- Session ID、CSRF Token 在设置页切换过程中仍只保留在本次应用内存中，不存入本地日志或浏览器存储。
- Python IPC 将配置参数错误与 Windows 凭据管理器故障区分处理；补充前端交互、折叠导航、敏感字段保留和 Python 回归测试。

## 保持原功能
- 保留知到、雨课堂的登录、课程读取、播放、进度查询及旧设置，不修改其服务端上报逻辑。
- 已下载的安装包仍需用户关闭学序并手动运行；此次不引入静默安装、自动执行或强制更新。
